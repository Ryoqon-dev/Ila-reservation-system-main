# 프로젝트 요약

일아 동아리 통합 관리 시스템은 동아리 대표와 총동아리연합회 관리자가 장소 대여와 동아리 정보를 같은 화면에서 관리하는 웹 애플리케이션입니다. 코드 기준 버전은 [package.json](../../package.json)의 1.10.1입니다.

## 대상 사용자

| 사용자 | 주된 업무 | 권한 경계 |
|---|---|---|
| 비회원 | 공지·안내·공개 목록 확인, 대표 계정 가입 | 관리자 정보·다른 동아리 예약 개인정보 접근 불가 |
| 승인 대기 대표 | 계정 상태 확인 | 승인 전 예약·조회·취소 불가 |
| 승인된 동아리 대표 | 대여 신청·자기 동아리 예약 확인·취소, 동아리 정보 확인 | 서버 세션의 동아리 기준; 대여 입장 권한은 별도 |
| 메인 관리자 | 예약·계정·동아리·벌점·사이트·데이터 운영 | 비밀번호+2차 인증, 민감 작업 재인증 |
| 조회 전용 관리자 | 최소 예약 목록·시간표 | 수정·민감정보·CSV 접근 불가 |
| 기간제 링크 소지자 | 지정 날짜·장소의 최소 예약 조회 | 토큰의 범위·만료·정지 조건으로 제한 |

구체적인 기능 경계는 [계정과 권한](../02-features/accounts-and-permissions.md), [예약 조회](../02-features/booking-access.md)가 기준입니다.

## 요청 흐름

브라우저는 [React 진입점](../../src/main.tsx)에서 화면을 구성합니다. API 요청은 [worker.mjs](../../worker.mjs)의 `/api/system`으로 들어가 [lib/service.mjs](../../lib/service.mjs) 및 기능 모듈을 거쳐 D1에 저장됩니다. 정적 화면·로고·건물 사진은 빌드 자산으로 제공합니다.

[시스템 개요](../03-architecture/system-overview.md)에 경계와 데이터 흐름을 설명합니다. 브라우저의 표시나 클라이언트 권한값만으로 예약 확정·관리자 인증을 인정하지 않습니다.

## 프로젝트 상태

현재 저장소에는 예약·자동 오픈·계정 승인·벌점·동아리 정보·사이트 편집·개인정보 암호화·예약 조회 권한 기능과 로컬 검증 코드가 있습니다. [기존 검사 기록](../07-todo-list/review-history/REVIEW.md)의 당시 자동·브라우저 검증과, 후속 PR의 새 검증 결과는 각각 별도 증거입니다.

운영 Cloudflare 계정, 실제 사용자 PC·휴대전화, 실제 DB 복원 훈련의 완료를 소스만으로 단정하지 않습니다. 확인이 필요한 업무는 [백로그](../07-todo-list/backlog.md)에 분리합니다.
