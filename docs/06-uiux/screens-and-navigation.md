# 화면과 탐색

앱은 `view` 쿼리와 React 상태로 화면을 전환합니다. 브라우저 뒤로 가기에서는 `popstate`로 화면을 다시 선택합니다. 관리자 내부 탭과 예약 내부 탭은 별도 React 상태이며 각각의 독립 주소를 만들지는 않습니다.

## 사용자 화면

| 주소 | 화면·진입점 | 주요 내용 |
|---|---|---|
| `/` | 첫 화면 | 배경 사진·대표 문구, 장소대여·내 동아리 카드, 문의 링크 |
| `/?view=guide` | 안내 | 관리자가 공개한 사진·제목·안내글 |
| `/?view=booking` | 대여 → 장소대여 | 대표 로그인, 날짜·장소·시간 선택, 우리 동아리 예약 |
| `/?view=equipment` | 대여 → 장비대여 | 공개 품목의 사진·설명 |
| `/?view=board` | 대여 → 보드게임 대여 | 공개 게임의 사진·구성·안내 |
| `/?view=club` | 내 동아리 | 대표 로그인, 현재 학기 벌점·전체 예약 이력 |
| `/?view=admin` | 관리자 | 메인 관리자·조회 전용 서브 관리자 진입 |
| `/?view=reservations` | 조회 전용 포털 | 조회 로그인·개인정보 없는 예약 목록·시간표 |

`view=account`는 `club`으로 정규화하고 알려지지 않은 값은 첫 화면으로 처리합니다. 상단 로고는 첫 화면으로 이동합니다. 내 동아리 메뉴는 로그인 시 아이디를 함께 보여줍니다. 장비·보드게임은 안내 목록이며 수량·날짜 예약이나 반납 처리 화면은 없습니다.

대여 하위 메뉴는 마우스 진입·클릭·터치로 열립니다. 아래 방향키는 첫 하위 버튼으로 초점을 이동하고 Esc는 닫은 뒤 대여 버튼에 초점을 돌려줍니다. 바깥 클릭·초점 이탈로도 닫습니다.

## 공지 진입 규칙

첫 화면 공지는 `homeNoticeEnabled`가 켜져 있으면 표시합니다. 확인한 제목·내용은 현재 앱 상태에 기억하고 동일 내용은 그 상태에서 다시 표시하지 않습니다. 영구적인 읽음 저장으로 보장하는 기능은 아닙니다.

장소·장비·보드게임은 각각 진입할 때마다 해당 이용 공지를 표시합니다. 새로고침·재입장·뒤로 가기 진입도 포함하며 예약 화면 내부 탭만 바꿀 때는 반복하지 않습니다. 이용 안내 버튼으로 다시 열 수 있습니다. 장소 공지는 활성 이용규정 항목, 장비·보드게임은 각 메뉴의 안내글을 표시합니다. 대여 권한 차단 안내가 열리면 이용 공지보다 우선 표시됩니다.

## 관리자 화면 구성

메인 관리자 로그인 후 관리 메뉴에서 다음 다섯 업무로 이동합니다.

| 관리 메뉴 | 내부 구성 |
|---|---|
| 장소대여 | 예약 오픈 / 예약 목록 / 동방점검·공휴일 설정 |
| 동방점검 | 기간별 통계 / 직접 벌점 입력 / 상세 내역·취소 |
| 현 동아리 | 방 배치도 / 교차 필터·검색 / 동아리·계정 관리 |
| 사이트 설정 | 기본 사이트 설정 / 안내 / 장비 / 보드게임 / 대여 팝업 공지 |
| 데이터·사용량 | 사용량, CSV, 학기 초기화·이전 기록 정리 |

예약 목록 아래 **예약 시간표**와 **조회 계정·링크 관리**는 접어서 표시하고 필요할 때 펼칩니다. 상단 관리자 메뉴 옆에는 남은 로그인 시간을 표시하며 1분 미만이면 만료 임박 스타일을 사용합니다. 계정·보안 설정은 상단 설정 버튼에서 엽니다.

## 사이트 표시 편집

기본 사이트 설정에서 학교·임기·단체·대표 이름·슬로건·문의 링크·첫 화면 공지와 로고·가로 로고·배경 사진을 편집합니다. **저장 전 미리보기**는 초안만 보여주며 **변경사항 저장** 뒤에 일반 화면으로 반영됩니다. 로고 이미지 안에 박힌 글자는 텍스트 입력으로 바뀌지 않으므로 이미지를 교체해야 합니다.

안내·장비·보드게임은 항목별 제목·본문·사진·공개 여부를 저장하고 순서 변경·삭제를 할 수 있습니다. 공개하지 않은 항목·사진은 일반 응답에서 제외합니다. 각 목록 최대 100개, 목록 이미지 총합 20MiB 한도입니다. 공지·브랜딩 문구 수정이 실제 예약 시간·벌점 규칙을 바꾸지는 않습니다. 다른 창이 먼저 저장하면 충돌을 표시하므로 최신 설정을 불러와 다시 편집합니다.
