# 사이트 설정 업데이트 — 임기 교체와 인수인계

현재 ZIP: 1.4.0 / data-management-v1

최신 운영 적용·첫 화면 공지·내 동아리 관리 안내는 **[CLUB_PORTAL_UPDATE.md](../../02-features/history/CLUB_PORTAL_UPDATE.md)**를 먼저 읽으세요. 아래는 1.2에서 추가된 사이트 설정 기능 안내입니다.
대상: https://ila-club-management.sunmoonclubunion.workers.dev

이 수정본에는 이전 대표 계정 업데이트도 함께 들어 있습니다. 이전 파일을 아직 적용하지 않았더라도 이 파일로 누적 업데이트할 수 있습니다. 기존 사이트 주소·계정·예약·벌점·DB 연결·보안 키·공개 설정을 유지합니다. Supabase·Vercel·별도 유료 저장소를 신청하지 않습니다.

## 운영 사이트에 한 번 적용하기

1. ZIP을 **기존 배포 폴더와 다른 새 폴더**에 압축 해제하세요. 바탕화면 `일아_사이트설정업데이트` 폴더처럼 구분하면 편합니다. 기존 운영 폴더를 삭제하거나 통째로 덮어쓰지 마세요.
2. 새 `ila-free-hosting` 폴더에서 **APPLY_SITE_UPDATE.cmd**를 더블클릭하세요.
3. ‘기존 배포 폴더 경로’에 예전에 Cloudflare 배포에 사용했던 다음 폴더를 입력하고 Enter를 누르세요.

```text
C:\Users\김주영\Desktop\36대 총동 파일\ILA_Free_Hosting\ila-free-hosting
```

4. 도구가 DB·키·기존 소스를 백업하고, 필요한 추가 테이블을 준비한 뒤 같은 사이트에 배포합니다. 계속할지 물으면 `y`와 Enter를 입력하세요.
5. **‘동아리 통합 관리 업데이트 및 배포 완료’**가 표시되면 완료입니다. 사이트를 열고 PC에서는 `Ctrl + F5`, 모바일에서는 새 시크릿 탭으로 접속하세요.

미리 빌드한 화면과 기존 Wrangler를 사용합니다. 다시 설치·빌드하거나 `prepare:hosting`, 공개 전환 명령을 실행할 필요가 없습니다. Cloudflare 로그인이 만료된 경우 기존 폴더에서 `npx wrangler login`을 실행하고 업데이트를 다시 실행하세요. 백업은 기존 폴더의 `backups/site-update-...`에 보관합니다. DB와 키가 함께 있으므로 공유하거나 웹에 업로드하지 마세요.

추가되는 0004 마이그레이션은 사이트 설정과 이미지 테이블만 만듭니다. 예약·동아리·계정·벌점 테이블을 초기화하지 않습니다. 이전 계정 업데이트를 적용하지 않은 경우 0003도 함께 적용합니다. 예전에 받은 ZIP의 도구가 아니라 **이번 ZIP에 포함된 도구**를 실행하세요.

## 관리자 화면에서 수정하기

1. 기존 관리자 아이디와 비밀번호로 로그인하세요.
2. 네 번째 메뉴 **‘사이트 설정’**을 선택하세요.
3. 필요한 항목을 수정하세요.
4. **‘저장 전 미리보기’**로 로고·문구·공지를 확인하세요.
5. **‘변경사항 저장’**을 누르세요. 이때 이미지와 문구가 함께 반영됩니다.

한 번 이 업데이트를 적용하면 이후 표시 정보 수정에는 코드를 고치거나 다시 배포할 필요가 없습니다. 새로 접속하거나 새로고침한 사용자에게 저장한 설정이 표시됩니다. 이미 열려 있는 화면은 창에 다시 돌아올 때 설정을 확인할 수 있지만, 모든 사용자의 화면이 동시에 바뀌는 실시간 전송 기능은 아닙니다.

저장 전 변경은 일반 사용자에게 보이지 않습니다. 화면을 이동하기 전 저장하세요. ‘최신 설정’을 누르면 확인 후 저장하지 않은 변경을 버리고 다시 불러올 수 있습니다. 다른 관리자 창에서 먼저 저장했다면 덮어쓰지 않고 충돌을 알려줍니다.

## 수정 가능한 항목

| 구분 | 항목 |
|---|---|
| 임기·단체 | 학교 이름, 대수, 단체명, 담당 부서, 대표 이름, 이름 옆 한자·보조 표기 |
| 이미지 | 대표 로고, 하단 가로 로고, 첫 화면 배경 사진 |
| 첫 화면 | 영문 표기, 큰 제목, 소개 문구, 슬로건 |
| 하단·문의 | 하단 소개 문구, 문의 오픈채팅 HTTPS 링크 |
| 공지·이용 안내 | 팝업 제목, 팝업 자동 표시 여부, 공지 추가·수정·삭제·순서·개별 표시 여부 |

대표 로고는 상단·로그인 화면·브라우저 아이콘에 함께 사용합니다. 대수·이름은 상단과 하단, 브라우저 제목·설명 등에 반영됩니다. 로고 이미지 안에 직접 적힌 ‘36대’, ‘일아’ 같은 글자는 텍스트 설정만으로 바뀌지 않으므로 새 로고 이미지로 교체하세요. 소개 문구 안에 적힌 이전 이름도 확인하세요.

대수는 1~999, 공지는 최대 10개까지 저장합니다. 공지 제목·내용은 일반 텍스트이며 줄바꿈을 지원합니다. HTML이나 스크립트를 실행하는 편집기는 제공하지 않습니다. **공지 문구를 고쳐도 예약 시간·4시간 제한·벌점 계산 같은 실제 운영 규칙은 바뀌지 않습니다.** 안내와 실제 규칙이 일치하게 작성하세요.

공지가 변경되면 이전에 읽은 사용자도 다음 예약 화면 진입 시 새 공지를 확인합니다. 로고·대수만 변경한 경우에는 읽은 공지를 다시 강제로 띄우지 않습니다. 자동 팝업을 꺼도 예약 화면의 ‘이용 안내’로 내용은 확인할 수 있습니다.

## 36대에서 다음 대로 바꾸는 예

1. 대수를 `37`로 입력합니다. 기본 형식의 영문 대수 표기도 함께 바뀌며, 영문 표기는 따로 수정할 수 있습니다.
2. 대표 이름과 보조 표기를 다음 대의 이름으로 수정합니다.
3. 대표 로고·하단 가로 로고를 새 이미지로 선택합니다. 배경 사진도 원하면 교체합니다.
4. 슬로건·첫 화면 소개·하단 문구·문의 링크를 확인합니다.
5. 다음 임기의 공지를 작성하고 필요 없는 이전 공지는 숨기거나 삭제합니다.
6. 미리보기 후 저장하고 PC·모바일에서 새로고침해 확인합니다.

이 설정은 **화면 표시를 바꾸는 기능**입니다. 기존 동아리 계정·예약·벌점이 새 대수로 바뀐다는 이유로 삭제되거나 초기화되지는 않습니다. 임기별 자료 분리나 이전 기수 자료 정리는 별도 작업입니다. Cloudflare 계정과 운영 담당자 권한도 별도로 안전하게 인수인계하세요.

## 이미지 용량과 안전 처리

- 원본 PNG·JPG·WebP, 10MB 이하를 선택합니다. 브라우저가 크기를 줄여 업로드용 이미지로 변환합니다.
- 저장 한도는 대표 로고·가로 로고 각각 192KiB, 배경 사진 768KiB입니다. 현재 이미지 3개만 보관합니다. 세 이미지의 원본 합계 한도는 약 1.125MiB이며 DB 메타데이터·인덱스 공간은 별도입니다.
- 별도 R2나 사진 저장 구독은 추가하지 않습니다. 설정과 현재 이미지가 기존 D1에 저장되며, 무료 요금제의 전체 사용량 제한은 그대로 적용됩니다.
- 서버에서 관리자 세션·파일 종류·실제 헤더·해상도·용량을 검사합니다. SVG와 움직이는 이미지는 지원하지 않습니다. 형식·크기·해상도 검사에서 확인한 기준에 맞지 않는 파일은 거절합니다.
- 새 이미지 선택만으로 운영 화면이 바뀌지 않습니다. 저장하면 설정·이미지·처리 기록을 함께 반영하고, 저장 실패 시 함께 되돌립니다.
- 이미지를 바꾸거나 ‘처음 제공된 이미지로 되돌리기’를 사용하면 새 이미지 주소가 반영되어 이전 캐시와 구분합니다. 이전 맞춤 이미지의 무제한 이력 보관·되돌리기 기능은 없습니다. 중요한 원본 파일은 따로 보관하세요.

## 적용 후 확인

- 기존 관리자·대표 계정 로그인, 승인, 예약·취소·여러 날짜 오픈·벌점 통계 유지
- 사이트 설정 메뉴 표시, 저장 전 미리보기, 저장 뒤 새로고침 반영
- 상단·로그인 로고, 하단 가로 로고, 배경 사진, 대수·슬로건·문의 링크 변경
- 새 공지 표시, 읽음 확인, 팝업 끄기, 공지 순서·숨김 동작
- 일반 동아리 계정으로 설정 변경이 차단되는지 확인

이 환경에서는 실제 운영 계정 배포와 PC·모바일 브라우저 클릭 검증을 수행하지 못했습니다. 자동 검사·타입 검사·빌드·로컬 Workers/D1 검증 범위는 [REVIEW.md](../../07-todo-list/review-history/REVIEW.md)에 적었습니다. 이 파일을 적용하기 전에는 운영 사이트가 변경되지 않습니다.
