# 안내·대여 목록·동아리방 배치도 업데이트

버전 1.6.0 / portal-catalog-rooms-v1 / 2026-10-26

## 이번 업데이트

- 상단 네 메뉴: 안내 / 대여 / 내 동아리(ID) / 관리자.
- 대여는 PC에서 마우스를 올리거나 클릭하면, 모바일에서는 누르면 장소대여·장비대여·보드게임 대여가 열립니다. 키보드 방향키·Enter·Esc도 지원합니다.
- 장소대여는 기존 예약·예약 내역·취소 기능과 첫 로그인자 단독 이용 정책을 유지합니다. 내 동아리와 관리자 기능도 유지합니다.
- 안내, 장비, 보드게임은 관리자가 사진·제목·설명을 등록하는 목록입니다. 순서 변경, 숨김, 사진 교체·삭제를 지원합니다. 이번 장비·보드게임 메뉴는 안내 목록이며 별도의 수량·날짜 예약 신청이나 반납 처리 기능은 포함하지 않습니다.
- 장소·장비·보드게임 메뉴에 들어갈 때마다 해당 공지가 열립니다. 이전 읽음 기록이나 과거 자동 표시 OFF 설정으로 생략하지 않습니다. 로그인 전 장소대여 진입, 새로고침, 재입장, 브라우저 뒤로 가기도 포함합니다. 메뉴 안에서 예약 탭을 바꾸는 것만으로는 반복하지 않습니다.
- 관리자 현 동아리 관리에서 회장·부회장·총무의 이름과 전화번호를 저장합니다. 임원 연락처는 관리자 API·화면에만 표시하고 일반 안내·동아리 회원 화면·CSV에는 포함하지 않습니다.
- 현 동아리 관리 상단에 3층 통합 배치도와 컨테이너 배치도, 2층 확인 호실 목록을 추가했습니다.

## 기존 운영 사이트 적용

1. 이번 ZIP을 기존 배포 폴더와 **다른 새 폴더**에 압축 해제합니다.
2. 새 폴더의 `ila-free-hosting` 안에서 **APPLY_SITE_UPDATE.cmd**를 실행합니다.
3. 기존 `wrangler.json`과 보안 키·배포 도구가 있는 실제 배포 폴더 경로를 입력합니다. 예전 경로를 그대로 사용했다면 다음과 같습니다.

```text
C:\Users\김주영\Desktop\36대 총동 파일\ILA_Free_Hosting\ila-free-hosting
```

4. 운영 DB·설정·키·이전 소스 백업 → 파일 적용 → 필요한 DB 마이그레이션 → 같은 주소 배포가 진행됩니다. 계속 여부를 물으면 `y`를 입력합니다.
5. ‘동아리 통합 관리 업데이트 및 배포 완료’를 확인합니다. PC는 Ctrl+F5, 휴대폰은 새 시크릿 창으로 새 화면을 불러옵니다.

현재 공개/비공개 설정을 유지합니다. 0008 마이그레이션은 안내 목록·임원 연락처·배치 변경·호실 연결용 테이블만 추가하며 기존 예약·계정·벌점·사이트 설정을 지우지 않습니다. 원본 첨부 파일의 비밀번호나 개인 연락처를 자동으로 가져오지 않습니다. 이 업데이트를 실행하기 전에는 운영 사이트에 반영되지 않습니다.

## 안내와 대여 목록 설정

관리자 → 사이트 설정에서 다음 탭을 선택하세요.

| 탭 | 설정 내용 |
|---|---|
| 기본 사이트 설정 | 로고·슬로건·임기·첫 화면 공지 등 기존 설정 |
| 안내 메뉴 설정 | 공간·활동 안내의 사진과 글 |
| 장비대여 목록 | 음향 장비 등 품목 사진과 설명 |
| 보드게임 목록 | 게임 사진·구성품·이용 안내 |
| 대여 팝업 공지 | 장소·장비·보드게임의 개별 공지 |

‘항목 추가’ → 제목·안내글 입력 → 사진 선택 → ‘항목 저장’ 순서입니다. 항목별 저장 즉시 반영되며, 각 목록은 처음에는 비어 있습니다. 확인되지 않은 장비 수량이나 공간 사진을 임의로 넣지 않았습니다. 내용을 작성한 탭에서 저장한 다음 다른 설정으로 이동하세요.

사진은 PNG·JPEG·WebP 원본 10MB 이하를 선택합니다. 브라우저에서 크기를 줄여 사진당 최대 192KiB로 준비하고 기존 D1 DB에 저장합니다. 각 목록은 최대 100개이며 세 목록의 이미지 합계는 20MiB로 제한합니다. DB의 실제 저장 크기는 이미지 외의 기록·인덱스·여유 공간도 포함합니다. R2나 유료 Images 구독은 추가하지 않습니다.

사진 교체·항목 삭제 시 이전 사진을 계속 쌓지 않습니다. 숨겨진 항목과 사진은 일반 사용자에게 제공하지 않습니다. 이미지·비밀번호는 CSV에 넣지 않습니다. 전체 복구 백업에는 새 자료도 포함됩니다.

## 대여 공지 설정

사이트 설정 → ‘대여 팝업 공지’에서 세 메뉴를 각각 편집하고 **세 대여 메뉴 공지 저장**을 누릅니다. 장소대여는 기존 소제목별 이용규정과 표시 여부를 그대로 이어받습니다. 장비·보드게임은 각각 제목과 안내글을 작성합니다.

대여 메뉴는 매번 입장 공지를 표시합니다. 첫 화면의 별도 공지 ON/OFF는 기존 방식대로 유지합니다. 공지 문구를 바꾸는 것이 예약 시간·벌점·승인 규칙을 바꾸는 것은 아닙니다.

## 임원 연락처

현 동아리 관리 → 동아리 정보 수정에서 회장·부회장·총무의 이름과 전화번호를 입력합니다. 비워둔 항목은 미등록으로 표시합니다. 전화번호는 하이픈을 입력해도 숫자만 정리해 저장하며 9~11자리로 확인합니다. 기존 계정을 수정하거나 비활성화할 때 연락처를 함께 지우지 않습니다.

## 배치도 사용과 이동

1. 현 동아리 관리 상단에서 학생회관 2층·3층·실외 컨테이너를 선택합니다.
2. 3층은 첨부한 두 화면을 공통 계단·로비 기준으로 연결한 **한 배치도**입니다. Excel 열 너비·행 높이와 병합 셀에 따른 상대 위치·방 크기를 유지했습니다. 실제 면적을 측량한 건축 도면은 아닙니다.
3. 방을 누르면 연결된 동아리의 계정 상태·호실·임원 연락처를 확인할 수 있습니다. 방 비밀번호는 별도의 확인 버튼으로 가려둡니다.
4. ‘호실·배정 변경’에서 호실과 표시 이름을 바꾸고 등록 동아리를 선택합니다. 다른 방에 있는 동아리를 선택하면 새 방으로 이동하고 기존 배정에서 빠집니다. 선택 해제된 동아리는 미배정으로 바뀝니다. 한 방에 여러 동아리를 연결할 수 있습니다.
5. 동아리 이름 자체를 바꾸려면 ‘동아리 정보 수정’을 사용합니다. 이름을 바꿔도 ID로 연결된 배정·계정·예약·벌점은 유지됩니다. 동아리 정보의 호실을 바꾸면 배치에도 반영됩니다.
6. 모바일에서는 배치도 안을 가로로 이동하고 확대·축소하거나 ‘호실 목록으로 찾기’를 사용하세요. 페이지 전체가 가로로 넘치지 않도록 구성했습니다.

배치명은 첨부 배치도를 초기 기준으로 사용합니다. 현황표와 배치도에서 313D·313K 등의 이름이 달라 임의로 통일하지 않았습니다. 기존 등록 동아리와 호실이 일치하면 연결하고, 연결 전 원본 배치명은 별도 색으로 표시합니다. 실제 운영 상태에 맞게 관리자가 확인·연결해주세요. 원본 이미지에 적힌 비밀번호는 웹 그림이나 배포 데이터에 포함하지 않습니다.

**2층 전체 도면은 첨부 자료에 없습니다.** 확인된 211D 신이데아만 위치·크기를 추정하지 않은 호실 목록으로 제공합니다. 2층 전체 사진이나 도면을 추가로 받아야 실제 비율에 맞는 2층 그림을 완성할 수 있습니다. 번호 없는 컨테이너 공간은 미지정 A·B·C로 구별하고 호실 편집으로 변경할 수 있습니다.

## 검증

- 자동 테스트 160개 통과. 기존 예약·로그인·벌점·데이터 관리 회귀 검사 포함.
- 목록의 공개/숨김·사진 검증·교체·삭제·용량 및 개수 제한·동시 수정·실패 롤백 검사.
- 임원 연락처 검증·보존·공개 및 CSV 제외, 배치도 관리자 인증·호실 이동 동기화·중복 호실·이전 버전 충돌·감사 기록 실패 롤백 검사.
- TypeScript, 운영 빌드, Worker dry-run, 실제 로컬 Worker·D1에서 사진 저장·조회·임원 정보·방 이동 및 기존 기능 검사.
- PC 브라우저에서 네 메뉴·대여별 공지·재입장 공지·안내글 저장과 일반 화면 반영·배치도 정보 조회·호실 변경 저장 확인.
- 브라우저 안 390px 모바일 화면에서 네 메뉴·대여 하위 메뉴·팝업·배치도·페이지 가로 넘침 검사. 실제 휴대폰 기기 검사는 별도입니다.

브라우저 검사는 임시 로컬 서버와 테스트 자료로 진행했습니다. 로컬 HTTP 미리보기용 세션·UUID 호환 처리는 운영 코드나 ZIP에 포함하지 않습니다. 사용자의 운영 Cloudflare 계정·DB에는 직접 배포하거나 자료를 변경하지 않았습니다.
