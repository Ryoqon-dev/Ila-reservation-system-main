# 사용자 흐름

현재 화면의 메뉴 이름을 따라 주요 작업을 정리합니다. 실제 운영 상태는 계정·오픈 설정·데이터에 따라 달라집니다.

## 대표 가입과 관리자 승인

1. **내 동아리** 또는 **대여 → 장소대여 → 회원가입**에서 소속 동아리·아이디·비밀번호를 입력합니다.
2. 접수 성공 뒤 로그인하면 승인 대기 안내를 확인합니다. 동아리가 가입 목록에 없으면 이미 계정이 있거나 비활성 상태일 수 있어 지원부에 확인합니다.
3. 메인 관리자가 **현 동아리 관리 → 가입 승인 대기 → 가입 승인**을 처리합니다.
4. 대표자는 다시 로그인합니다. 승인하면 이전 승인 대기 세션은 무효화됩니다.

관리자가 직접 발급하는 경우에는 **현 동아리 → 계정 추가**에서 아이디·비밀번호·상태를 저장합니다. 신규 비밀번호 저장에는 관리자 재인증을 요구합니다. 승인 전 대표자와 소속의 확인은 관리자의 운영 절차입니다.

## 예약과 취소

1. **대여 → 장소대여**에서 공지를 확인합니다. 로그인했더라도 다른 로그인에 대여 권한이 있으면 차단 안내가 나옵니다.
2. 날짜·장소·연속 시간을 고르고 신청자·연락처·규정 동의를 입력합니다.
3. 예약 성공 화면에서 날짜·장소·시간을 확인합니다. 중복 선점 오류가 나오면 최신 시간표를 보고 다시 고릅니다.
4. **우리 동아리 예약**에서 자기 동아리 예약을 조회하고 시작 전 예약을 취소합니다. 확인 대화상자 뒤 서버 결과를 확인합니다.
5. **내 동아리 → 예약 내역**에서도 과거·취소 포함 전체 이력을 조회할 수 있습니다. 이 화면은 조회용이며 취소 경로 안내를 제공합니다.

내 동아리는 여러 로그인에서 함께 이용할 수 있고, 예약·취소는 대여 권한 소유 로그인에서 처리합니다. 실제 시작 시각에 대한 최종 취소 판단은 서버가 합니다. 화면에 취소 버튼이 남아 있어도 시작된 예약 요청은 거절될 수 있습니다.

## 오픈과 예약 운영

1. **관리자 → 장소대여 → 예약 오픈**에서 대여 날짜·장소를 선택합니다.
2. 즉시 접수하려면 **지금 오픈·마감**, 예약 접수 시각을 정하려면 **시간 지정 자동 오픈**을 선택합니다.
3. 저장 뒤 오픈 현황·자동 오픈 목록을 확인합니다. 자동 오픈 대기는 시작 전 취소할 수 있고, 시작 뒤에는 수동 마감을 사용합니다.
4. **예약 목록**에서 기간·정렬·검색·상태로 찾고 사진 확인·취소를 처리합니다. 취소한 예약만 목록에서 삭제할 수 있습니다.
5. 예외 예약은 **관리자 추가승인**에서 사유와 필수 항목을 입력합니다. 중복·이미 시작한 시간은 추가승인도 허용하지 않습니다.

## 사진 확인과 벌점 정정

1. 외부 제출된 사진을 확인하고 **예약 목록 → 사진 제출/미제출**로 입·퇴실 상태를 함께 기록합니다.
2. 이용 종료 후 사진이 미확인이라면 예약 목록의 **사진 미제출 -10점** 또는 **동방점검 관리**의 직접 입력을 사용합니다.
3. 동아리별 통계·상세 내역에서 날짜·종류·사유·점수를 확인합니다. 같은 동아리·날짜의 사진 벌점은 한 번만 부과합니다.
4. 잘못 입력했다면 **기록 취소**로 집계에서 제외합니다. 현재 학기의 취소된 사진 벌점은 정정 입력할 수 있습니다.
5. 대표자는 **내 동아리**를 새로고침해 사진·점검·총합과 사유를 확인합니다.

## 조회 계정·링크와 시간표

1. 메인 관리자는 **장소대여 → 예약 목록 → 조회 계정·링크 관리**를 펼칩니다.
2. 조회 계정을 추가하거나 만료 링크의 이름·허용 날짜·장소·만료 한국시간을 입력합니다. 비밀번호와 인증 코드로 본인 확인 후 저장·발급합니다.
3. 발급된 링크는 즉시 복사합니다. 허용 대여 날짜는 최대 7일이며 링크 만료는 발급부터 최대 365일입니다.
4. 수신자는 링크를 열어 조회 전용 포털에 진입합니다. 조회 계정 이용자는 별도 아이디·비밀번호로 로그인합니다.
5. 예약 목록의 기간·정렬을 선택하거나 **예약 시간표**를 펼쳐 하루를 조회합니다. **이미지 저장**은 최신 자료로 PNG를 만듭니다.
6. 종료하려면 조회 종료/로그아웃을 누릅니다. 만료·정지 안내가 나오면 유효한 주소나 계정을 다시 확인합니다.

조회 화면은 개인정보·수정 버튼을 제공하지 않습니다. 조회 전용 계정으로 전환하면 같은 브라우저의 메인 관리자 권한은 해제됩니다. 상세 제한은 [예약 접근과 조회](../02-features/booking-access.md)를 참고하세요.
