# 반응형과 화면 상태

이 문서는 CSS와 React 이벤트 처리에서 확인한 동작입니다. 실제 기기에서 모든 레이아웃·접근성 기준을 통과했다는 검증 보고가 아닙니다.

## 화면 크기와 입력 방식

기본 스타일은 크림 배경·짙은 녹색 본문·녹색 주요 버튼·둥근 카드·한국어 시스템 폰트 계열을 사용합니다. 공통 최대 폭, 입력 필드 높이, 선택·오류·비활성 색상은 `styles.css`에 정의되어 있습니다. 주된 작은 화면 전환은 760px 이하이며 1000px·900px·680px·540px·430px·370px 등 컴포넌트별 보완 규칙도 있습니다.

- 예약·로그인·관리의 여러 열 구성을 좁은 화면에서 재배치합니다. 일부 스티키 영역과 글자·여백·버튼 배치도 화면 폭에 맞춰 조정합니다.
- 긴 관리자 탭과 사이트 설정 탭은 좁은 화면에서도 선택할 수 있도록 CSS에서 배치·넘침을 조정합니다.
- 배치도는 내부 가로 이동·확대/축소와 호실 목록 찾기를 제공합니다. 2층은 전체 도형 대신 확인 호실 목록을 보여줍니다.
- 시간표는 내부 좌우 이동 영역을 제공하며 `tabIndex=0`과 “좁은 화면에서는 좌우 이동” 설명을 포함합니다. 텍스트 보기로 같은 예약을 읽을 수 있습니다.
- 마우스 호버 외에 대여 메뉴의 클릭·터치·키보드 진입을 지원합니다. `prefers-reduced-motion: reduce` 규칙도 포함합니다.

## 동아리 편집 팝업

동아리 등록·수정은 전용 `<dialog>`에서 처리합니다. 제목·닫기와 저장·취소는 입력 본문과 분리하고 본문을 내부 스크롤 영역으로 구성합니다. 열 때 배경 스크롤을 잠그고 닫으면 이전 overflow 설정과 원래 버튼의 초점을 복원합니다.

입력을 바꾼 뒤 닫기·Esc·취소를 시도하면 저장하지 않은 변경 확인을 요청합니다. 저장 중에는 닫기·취소·입력을 막습니다. 실패하면 오류를 표시하고 입력은 유지합니다. 이 보호 동작은 `ClubEditorDialog`에 구현되어 있으므로 모든 일반 팝업이 같은 미저장 확인을 제공한다고 해석하지 마세요.

## 로딩·빈 상태·실패

| 상황 | 화면의 대응 |
|---|---|
| 사이트 최초 조회 | 사이트 정보 로딩 안내 |
| 표시 설정 갱신 실패 | 상단 갱신 실패 안내, 새로고침·관리자 확인 유도 |
| 계정 확인 중 | 대표/관리자/조회 권한을 확인하는 메시지 |
| 조회 중 | 예약·벌점·목록별 로딩 문구와 작업 버튼 비활성화 |
| 조회 결과 없음 | 빈 목록·예약 없음·적용된 벌점 없음 안내 |
| 저장 중 | 저장 중 문구와 관련 입력·중복 실행 제한 |
| 요청 실패 | 오류 영역 또는 토스트, 필요한 곳에서 다시 불러오기·새로고침 |
| 다른 창의 수정 | 버전 충돌 안내, 최신 목록·설정 다시 읽기 |
| 대여 권한 없음 | 단독 이용 안내와 권한 다시 확인, 내 동아리 이동 |
| 조회 링크 만료·정지 | 권한 해제, 유효한 링크로 재접속 안내 |

여러 조회 컴포넌트는 순서 번호를 사용해 늦게 도착한 과거 요청이 최신 상태를 덮어쓰지 않도록 합니다. 모든 목록의 실패 처리 방식이 같지는 않습니다. 예를 들어 시간표는 실패 시 자료를 비우고, 일부 목록은 기존 자료와 오류를 함께 남길 수 있습니다.

## 로그인 만료와 시각 표시

메인 관리자 상단 남은 시간은 서버가 보낸 미사용 만료 시각을 기준으로 표시하고 1분 미만일 때 스타일을 바꿉니다. 메인 관리자와 조회 계정은 15분 미사용·최대 8시간이며 단순 자동 조회가 활동으로 간주되지는 않습니다. 실제 입력과 서버의 활동 API가 기간을 갱신합니다.

예약 날짜·현재 한국시간·자동 오픈 카운트다운은 서버 시각을 관찰해 표시합니다. 시간표와 오픈 화면은 포커스 복귀·표시 상태·예정 시각에 맞춰 갱신하는 처리가 있지만 네트워크 지연이 생길 수 있습니다. 실제 저장 성공 응답이 예약 확정 기준입니다.

## 접근성 관련 구현과 확인 범위

버튼·링크·입력에 `:focus-visible` 윤곽선을 제공하고 아이콘 버튼에는 닫기·새로고침 등의 `aria-label`을 사용합니다. 선택 필터와 사진 버튼은 `aria-pressed`, 펼치기 버튼은 `aria-expanded`를 사용합니다. 오류·상태 메시지 일부에는 `role=alert` 또는 `role=status`를 부여하고 이미지에는 용도에 맞는 대체 텍스트를 넣습니다. 배치도의 방은 Enter·Space로 선택할 수 있습니다.

저장소의 [render-check.tsx](../../tests/render-check.tsx)는 여러 컴포넌트를 정적 마크업으로 렌더하는 검사 도우미입니다. [시간표 모델 테스트](../../tests/reservation-timetable.test.mjs)와 [사진 동작 테스트](../../tests/photo-submission.test.mjs)는 관련 상태를 검증합니다. 이 근거만으로 실제 브라우저의 초점 이동·스크린리더·대비·터치 동작을 모두 검증했다고 주장할 수는 없습니다. 과거 브라우저 확인 범위는 [PORTAL_LAYOUT_UPDATE.md](history/PORTAL_LAYOUT_UPDATE.md)에 별도로 남겨두었습니다.
