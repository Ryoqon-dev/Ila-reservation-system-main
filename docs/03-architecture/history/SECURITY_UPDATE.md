> 현재 누적 업데이트(1.9.1)의 관리자 미사용 만료 시간은 15분입니다. 기존 2차 인증과 계정 수정 재인증은 유지합니다.

# 보안 업데이트 1.8.0

기존 누적 기능과 운영 주소를 유지하는 업데이트입니다. 실제 운영 사이트 적용은 아래 명령을 사용자 PC에서 완료해야 합니다.

## 적용
1. 새 ZIP을 **기존 배포 폴더와 다른 폴더**에 압축 해제합니다.
2. 새 폴더의 `APPLY_SITE_UPDATE.cmd`를 실행하고 기존 `wrangler.json`이 있는 배포 폴더를 입력합니다.
3. **DB 백업 암호**와 **키 보관용 별도 암호**를 각각 12자 이상으로 정하고 두 번 입력합니다. 입력은 화면에 보이지 않습니다. 두 암호는 서로 다르게 정하고 안전하게 보관하세요.
4. 도구 설치, DB 백업·기존 백업 암호화, 추가 테이블 준비, 보안 키 등록, 배포, 기존 개인정보 암호화·검증이 순서대로 진행됩니다. 암호화 중에는 예약 API가 잠시 503을 반환합니다. 실패하면 같은 업데이트를 다시 실행하세요. 임의로 키를 바꾸거나 DB를 새로 만들지 마세요.
5. 완료 후 사이트의 관리자 메뉴에서 기존 관리자 ID·비밀번호로 로그인하고 인증앱을 등록합니다. 기존 관리자 접속은 해제됩니다. 동아리 계정·예약·벌점은 유지됩니다.

## 관리자 인증
- 스마트폰에 Google Authenticator 등 TOTP 인증앱을 준비합니다. 인증앱에서 계정 추가 → QR 스캔 → 화면의 6자리 코드 입력 순서로 등록합니다. QR은 서버로부터 받은 설정 키를 브라우저에서 직접 그립니다. 외부 QR 서비스로 보내지 않습니다.
- 이후 로그인은 ID·비밀번호 → 인증앱 코드 순서입니다. 2차 인증 전에는 관리자 개인정보 조회·수정 API를 사용할 수 없습니다.
- 같은 OTP는 다시 사용할 수 없습니다. 바로 다음 민감 작업에서는 인증앱의 다음 코드를 기다리거나 사용하지 않은 복구 코드를 입력하세요.
- 복구 코드 10개는 한 번만 표시되며 각 1회용입니다. DB에는 원문을 저장하지 않습니다. 비밀번호와 별도로 보관하세요.
- 관리자 메뉴의 계정·보안에서 계정 수정, 인증앱 교체, 복구 코드 재발급을 할 수 있습니다. 기존 비밀번호와 새로운 2차 인증이 필요합니다. 계정 수정은 모든 관리자 세션을 해제합니다. 인증앱 교체는 다른 기기의 세션과 이전 복구 코드를 해제합니다.
- 관리자 메뉴를 **15분 동안 사용하지 않으면 만료**됩니다. 자동 새로고침은 사용으로 계산하지 않습니다. 서버에서도 검사합니다. 계속 사용해도 8시간 후 다시 로그인해야 합니다. 동아리 사용자 로그인 유지 정책은 기존과 같습니다.
- 동아리 비밀번호는 해시만 보관하고 원문 조회를 폐지합니다. 기존 비밀번호는 유지되며 관리자 계정 수정에서 새 비밀번호를 설정할 수 있습니다. 동아리 비밀번호 재설정·계정 삭제, 방 비밀번호 조회, 학기 초기화·영구 삭제, 사용량 연결 변경에도 관리자 재인증이 필요합니다.

## 암호화·백업
- 임원 이름·전화번호·학번, 지도교수, 예약자·전화번호·메모·추가승인 사유, 벌점 사유를 AES-256-GCM으로 암호화합니다. 암호화 키 PII_KEY와 인증앱 키 MFA_KEY는 D1에 넣지 않습니다. 기존 ROOM_KEY·BOOKING_KEY는 유지합니다.
- 기존 정보를 암호화하고 누락이 없는지 확인한 뒤 API를 활성화합니다. 전환 후에는 DB 트리거도 개인정보 원문 저장을 거부합니다. 중단된 전환은 재실행할 수 있습니다.
- DB 백업은 `backups/.../database.ila-backup`, 키 백업은 `.secrets/key-backups/*.ila-keys`에 서로 다른 암호로 저장합니다. 기존 `backups` 아래 `database.sql`·`runtime.json`도 검증한 암호화 파일로 전환한 다음 원문을 제거합니다.
- `BACKUP_DATA.cmd`는 같은 방식으로 백업합니다. `RESTORE_BACKUP.cmd`는 파일과 해당 암호를 받아 새 `recovered-*` 폴더에 복호화합니다. 운영 DB에 자동 덮어쓰지 않습니다.
- Wrangler가 내보내는 SQL은 잠시 `.secrets`에 만들어졌다가 암호화 후 성공·실패와 관계없이 삭제됩니다. PC가 강제로 종료되면 남을 수 있으므로 `.secrets/backup-*.sql`을 확인하세요. 디스크 복구 도구·클라우드 파일 버전·이미 공유한 사본까지 지우는 기능은 아닙니다.
- `.secrets/runtime.json`은 배포에 필요한 실제 키입니다. 기존 배포 폴더와 PC 계정을 안전하게 유지하고 키 백업은 DB 백업과 다른 저장 매체에도 보관하세요. 이 파일을 잃으면 개인정보를 복호화할 수 없습니다. 백업 암호를 서버에 저장하지 않습니다.
- CSV는 기존처럼 이미지·비밀번호·임원 학번/연락처를 제외합니다. 예약 CSV는 운영에 필요한 예약 대표자·연락처를 포함하므로 관리자만 다운로드합니다.

## 추가 운영 권장
Cloudflare 계정에도 2차 인증을 켜세요. D1 Time Travel의 전환 전 복구 지점에는 과거 원문이 남을 수 있습니다(현재 Free 보관 기간 7일). Cloudflare 계정과 이전에 다른 곳에 복사한 백업도 보호해야 합니다. 이 사이트가 Cloudflare 계정 설정을 대신 변경하지는 않습니다. 인증앱은 피싱을 완전히 막지 못합니다. 관리자 PC·브라우저·휴대전화와 백업 암호 보호, 개인정보의 학기별 보관 기한 관리가 필요합니다. 향후 개인별 관리자 계정·권한 분리와 패스키를 추가할 수 있습니다.
