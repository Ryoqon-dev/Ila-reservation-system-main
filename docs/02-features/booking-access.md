# 예약 접근과 조회

동아리의 장소대여 단독 이용 권한과 운영 지원용 예약 조회 권한은 별개입니다. 전자는 예약·취소를 허용하고, 후자는 개인정보를 제외한 목록·시간표만 제공합니다.

## 같은 대표 계정의 여러 로그인

대표 계정은 여러 기기에서 로그인하고 **내 동아리**의 예약 이력·벌점을 함께 조회할 수 있습니다. **장소대여**의 예약 저장·대여용 예약 목록·취소·기존 확인서 API는 동아리별 한 로그인에만 허용됩니다. 다른 접속에는 “장소 대여 메뉴는 한 명만 입장 가능합니다.” 안내를 보여주고 서버도 423으로 거절합니다.

대여 권한은 먼저 로그인한 활성 세션에 임대로 부여합니다. 화면이 보일 때 60초마다 확인하고, 소유 세션은 마지막 확인에서 3분간 권한을 유지합니다. 대기 세션은 현재 소유자의 만료를 연장하거나 권한을 빼앗지 못합니다. 로그아웃 또는 만료 뒤 가장 먼저 로그인한 남은 활성 세션이 다음 확인에서 이어받습니다. 자동 확인까지 추가로 최대 약 1분이 걸릴 수 있어 **이용 권한 다시 확인**으로 확인할 수 있습니다.

같은 브라우저의 탭들은 하나의 쿠키를 공유합니다. 이 정책은 계정 하나당 탭 하나를 강제하는 기능이 아닙니다. 대표 계정의 최대 8시간 로그인 유효기간도 3분 대여 임대와 별도입니다.

## 조회 전용 계정과 기간제 링크

메인 관리자 **장소대여 → 예약 목록 → 조회 계정·링크 관리**에서 발급합니다. 발급·수정에는 현재 관리자 비밀번호와 새로운 인증 코드가 필요합니다.

| 구분 | 조회 계정 | 기간제 링크 |
|---|---|---|
| 진입 | 관리자 화면의 조회 전용 서브 관리자 또는 예약 조회 포털 | 발급한 주소 열기 |
| 인증 | 아이디·비밀번호, 인증앱 불필요 | 주소의 인증값을 공유 전용 세션으로 교환 |
| 범위 | 요청당 최대 31일, 목록 100건씩 | 발급 시 정한 대여 날짜·장소만 조회 |
| 유효기간 | 15분 미사용·로그인 최대 8시간 | 발급 시점부터 최대 365일의 만료 시각 |
| 날짜 제한 | 발급 링크의 고정 범위를 사용하지 않음 | 시작·종료 포함 최대 7일 |
| 세션 쿠키 | 계정 로그인 세션 | 링크 만료와 7일 중 먼저 도래하는 시각까지 |
| 회수 | 계정 수정·사용 중지 시 기존 접속 종료 | 링크 정지·만료 시 다음 요청부터 거절 |

**링크의 유효기간 365일과 조회 가능한 대여 날짜 7일은 다른 제한입니다.** 365일 링크도 지정한 7일 이내의 예약만 조회합니다. 공유 세션 쿠키가 7일 후 끝나면 링크 자체가 유효한 동안 받은 주소를 다시 열 수 있습니다.

목록과 시간표에는 날짜·장소·시작·종료·동아리명·예약 상태만 제공합니다. 신청자·전화번호·메모·추가승인 사유·방 비밀번호·학번·예약코드는 전달하지 않습니다. 조회 계정이나 링크로 일반 관리 API를 직접 호출해도 관리자 권한을 얻을 수 없습니다. 같은 브라우저에서 조회 계정 로그인을 하면 해당 브라우저의 메인 관리자 권한은 해제됩니다.

링크는 전달받은 사람이 다시 공유할 수 있습니다. 발급 직후 주소를 복사해 보관해야 하며 이후 목록에서는 원래 인증값을 다시 조회할 수 없습니다. 서버에는 링크 인증값과 세션값의 해시를 저장하고, 브라우저는 주소 조각의 인증값을 교환하면서 화면 URL에서 지웁니다.

활성 링크는 최대 100개이며 관리 목록은 활성 우선 최대 100건을 표시합니다. 발급 응답을 받지 못해 주소를 확보하지 못했다면 해당 링크를 정지하고 새로 발급합니다. 조회 전용 목록은 취소 예약을 포함하고 삭제 예약은 제외합니다.

## 예약 시간표와 PNG

메인 관리자 예약 목록과 조회 전용 포털에서 **예약 시간표**를 펼치고 날짜를 선택합니다. 목록의 기간·검색과 독립적으로 하루의 확정·추가승인 예약을 조회하며 취소·삭제 예약은 제외합니다. 시간축은 09:00~21:00이며 칸에는 동아리명만 표시합니다. 빈 칸은 예약 내역 없음이며 일반 예약 접수 가능 여부를 보장하지 않습니다.

작은 화면에서는 시간표 안을 좌우 이동할 수 있고 **시간표 텍스트로 보기**를 제공합니다. 이미지 저장은 최신 하루 자료를 다시 조회한 뒤 1440×1536 PNG를 생성합니다. 공유 링크 이용자의 시간표도 허용 날짜·장소를 벗어날 수 없습니다. 표시 한도를 넘는 응답은 일부 자료로 이미지를 만들지 않고 오류를 표시합니다.
