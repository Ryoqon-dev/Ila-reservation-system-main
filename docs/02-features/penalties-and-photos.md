# 벌점과 사진 확인

관리자가 입·퇴실 사진 제출 상태와 동방점검·사진 미제출 벌점을 기록합니다. 대표 계정은 **내 동아리**에서 자기 동아리의 현재 학기 누적 점수와 사유를 확인합니다.

## 사진 제출 상태

예약 목록의 **사진 제출/미제출** 버튼은 입실·퇴실 두 값을 함께 변경합니다. 두 값이 모두 참일 때만 제출로 표시합니다. 과거 기록에서 하나만 확인된 경우 어떤 사진이 확인됐는지 도움말에 나타나며, 다음 버튼 조작은 둘을 함께 제출 처리합니다. 취소·삭제 예약에서는 변경할 수 없습니다.

이 버튼은 **확인 여부 기록**입니다. 장소 이용 사진 자체를 업로드하거나 저장하는 기능이 아닙니다. 사이트 로고·품목 사진 업로드와 구분하세요. 예약 사진은 외부로 제출한 뒤 관리자가 상태를 기록하는 흐름입니다.

## 벌점 적용 방법

| 경로 | 조건·기본값 |
|---|---|
| 예약 목록의 사진 미제출 버튼 | 활성 예약의 이용 종료 후, 입·퇴실 중 하나라도 미확인일 때 기본 10점 |
| 동방점검 관리의 직접 입력 | 종류 `inspection` 또는 `photo`, 동아리·날짜·사유·양의 점수 입력 |
| 직접 입력 검증 | 오늘 또는 과거 날짜, 사유 최대 500자, 정수 1~1000점. 기본 UI 점수 10점 |

사진 벌점은 **동아리·날짜별 한 번**만 활성 상태로 적용합니다. 예약이 여러 건이거나 예약 목록과 직접 입력을 동시에 사용해도 중복 부과하지 않습니다. 직접 입력한 점수·사유가 있으면 예약 목록의 간편 부과가 이를 덮어쓰지 않습니다. 동일 날짜의 직접 입력을 다시 시도하면 중복 오류가 납니다. 동방점검 벌점에는 이 일일 사진 전용 키를 적용하지 않습니다.

사진 제출 확인을 바꿔도 이미 부과한 벌점이 자동 취소되지는 않습니다. 잘못 부과한 점수는 상세 내역에서 **기록 취소**를 사용하세요. 취소한 현재 학기 사진 벌점은 정정한 사유·점수로 다시 입력할 수 있습니다.

## 집계·취소·학기 경계

관리자 통계는 선택 기간의 취소되지 않고 학기 마감되지 않은 벌점을 동아리별로 합산합니다. 상세 내역은 최근 1,000건까지 표시하며 통계는 전체 대상 내역으로 계산합니다. 취소한 내역 포함 여부를 화면에서 선택할 수 있습니다.

내 동아리에서는 사진 점수·일수, 점검 점수·건수, 총합을 분리해 표시합니다. 사유는 전체·사진·점검으로 필터하고 30건씩 조회합니다. 사유 페이지나 필터를 바꿔도 총합은 전체 현재 학기 기준을 유지합니다. 예약 페이지는 벌점 페이지와 별개로 움직입니다.

취소는 `voided` 표시를 남기고 합계에서 제외합니다. 이미 마감된 학기의 기록은 수정·재부과할 수 없습니다. 학기 초기화와 이전 자료 정리는 관리자 **데이터·사용량 관리**의 별도 절차입니다.
