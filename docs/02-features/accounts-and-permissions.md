# 계정과 권한

메인 관리자, 동아리 대표, 조회 전용 서브 관리자, 기간제 조회 링크를 서로 다른 접근 경로로 처리합니다. 화면에서 버튼을 숨기는 것과 함께 서버가 로그인·역할·소속·저장 시점의 권한을 검사합니다.

## 역할별 범위

| 역할 | 가능한 작업 | 주요 조건 |
|---|---|---|
| 비로그인 | 첫 화면·안내·공개 품목 목록, 가입 가능한 동아리·예약 가능 시간 조회 | 예약 저장·관리 데이터 접근 불가 |
| 승인 대기 대표 | 로그인, 승인 상태 확인, 자기 계정 변경 | 예약과 내 동아리 보고서 접근 불가 |
| 승인 대표 | 자기 동아리 벌점·전체 예약 이력 조회 | 다른 동아리 정보 접근 불가 |
| 대여 권한을 가진 승인 대표 | 장소 예약·자기 예약 목록·시작 전 취소 | 동아리별 한 로그인에 대여 권한 |
| 메인 관리자 | 예약·오픈·동아리·계정·벌점·사이트·데이터 관리 | 비밀번호와 2차 인증 완료 |
| 조회 전용 서브 관리자 | 개인정보 없는 예약 목록·시간표 | 별도 계정 로그인, 관리·예약 변경 불가 |
| 기간제 조회 링크 이용자 | 지정 날짜·장소의 개인정보 없는 예약 조회 | 유효하고 정지되지 않은 링크 필요 |

## 대표 계정의 생명주기

동아리당 대표 계정은 한 개입니다. 활성 동아리 중 아직 계정이 없는 동아리만 가입 선택지에 나옵니다. 가입은 `PENDING`으로 접수되고 관리자가 `APPROVED`로 승인해야 예약할 수 있습니다. 관리자는 계정을 직접 발급하거나 `SUSPENDED`로 이용 정지할 수도 있습니다. 승인·계정 수정 후에는 이전 세션이 무효가 되므로 새 정보로 다시 로그인합니다.

아이디는 영문·숫자·`.`·`_`·`-` 4~40자이며 대표 계정 아이디의 대소문자는 구분하지 않습니다. 신규 비밀번호는 10~128자입니다. 본인 변경에는 현재 비밀번호가 필요합니다. 새 비밀번호를 비워두면 기존 비밀번호를 유지하지만 계정 변경 자체가 전체 기기의 접속을 무효화합니다. 계정의 소속 동아리를 다른 동아리로 옮길 수 없습니다.

대표 계정은 최대 8시간 유효하며 여러 기기에서 함께 로그인할 수 있습니다. 로그아웃은 해당 브라우저의 세션만 종료합니다. 관리자 초기화·수정·정지·삭제와 동아리 비활성화는 관련 이전 접속을 무효화합니다. 계정 삭제가 기존 예약·벌점을 삭제하지는 않습니다. 장소대여만 한 로그인에 허용하는 자세한 규칙은 [예약 접근](booking-access.md)을 참고하세요.

현재 대표 계정 비밀번호는 해시로 저장하며 관리자도 원문을 조회할 수 없습니다. `accountSecret`은 원문 대신 410 오류를 반환합니다. 방 비밀번호 조회는 다른 기능으로, 관리자 본인 확인 후에만 제공합니다.

## 메인 관리자 로그인과 재인증

최초 관리자 설정에는 서버에 준비된 최초 설정 키가 필요하며 이미 관리자가 있으면 다시 만들 수 없습니다. 일반 로그인은 아이디·비밀번호 확인 후 인증앱 6자리 코드 또는 남은 일회용 복구 코드로 완료합니다. 최초 인증앱 등록 때 복구 코드 10개를 제공하며 보관 확인을 마쳐야 계속 진행합니다.

메인 관리자 세션은 **15분 미사용 또는 로그인 후 최대 8시간**에 만료됩니다. 자동 조회는 미사용 시간을 갱신하지 않습니다. 관리자 화면의 실제 사용자 입력에 따라 `adminActivity`를 보내고 서버가 남은 만료 시각을 반환합니다. 계정·인증앱 변경과 복구 코드 재발급은 관리자 보안 화면에서 처리합니다.

계정 비밀번호 설정·계정 삭제·방 비밀번호 조회·조회 계정 및 링크 발급 등 민감한 작업은 현재 관리자 비밀번호와 새로운 인증 코드로 추가 본인 확인을 요구합니다. 실패·만료·중복 사용된 코드는 다시 사용할 수 없습니다. 인증 쿠키는 HttpOnly·Secure·SameSite 속성을 사용합니다.

## 조회 계정과 공유 링크

조회 계정은 인증앱 없이 별도의 아이디·비밀번호로 로그인하지만 메인 관리자 권한을 얻지 않습니다. 조회 계정의 15분 미사용·최대 8시간 정책과, 링크의 최대 365일 유효기간·최대 7일 허용 대여 날짜 범위는 구분해야 합니다. 발급·정지·세션별 동작은 [예약 접근과 조회](booking-access.md)에 정리했습니다.
