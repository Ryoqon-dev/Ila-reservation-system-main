# 동아리 관리

**메인 관리자 → 현 동아리 관리**에서 동아리 기본 정보·대표 계정·임원·프로필과 방 배정을 관리합니다. 일반 대표 계정의 **내 동아리**는 예약·벌점 조회 화면이며 관리자 편집 기능과 구분됩니다.

## 정보 항목

| 항목 | 내용·검증 |
|---|---|
| 기본 정보 | 동아리명, 호실, 활성 여부, 선택 방 비밀번호 |
| 동아리 상태 | 미지정 또는 정동아리·준동아리·신규동아리 |
| 상태 기준일 | 상태가 있으면 오늘 또는 과거의 실제 날짜. 상태 미지정이면 비움 |
| 분과 | 미지정 또는 공연·봉사·체육·교양/학술 |
| 회원 수 | 미등록 또는 정수 0~100000명 |
| 지도교수 | 선택, 앞뒤 공백 제거 후 최대 40자 |
| 임원 | 회장·부회장·총무의 이름·전화번호·학번 |
| 임원 검증 | 이름 최대 40자, 전화번호는 비어 있거나 숫자 9~11자리, 학번은 비어 있거나 숫자 10자리 |

학번은 문자열로 처리해 앞자리 0을 보존합니다. 임원 정보와 지도교수 등 관리 정보는 공개 목록·동아리 보고서·계정 CSV에 노출하지 않습니다. 대표 계정의 승인 상태와 동아리의 정/준/신규 상태는 서로 독립적입니다.

## 등록·수정과 목록 찾기

1. 목록 상단 **동아리 등록** 또는 카드의 **동아리 정보 수정**을 누릅니다. 상세 화면·배치도의 수정도 같은 편집 팝업을 사용합니다.
2. 기본 정보와 필요한 프로필·임원을 입력합니다. 상태를 바꾸면 기준일로 오늘을 제안하며 수정할 수 있습니다.
3. 저장 뒤 목록·상세·배치도에 반영된 내용을 확인합니다. 실패하면 입력이 유지되며 오류를 수정해 다시 저장합니다.

목록에서는 계정 상태, 동아리 상태, 분과를 함께 선택하고 이름·호실·계정 아이디로 검색할 수 있습니다. 기본 목록은 활성 동아리이며 비활성 포함을 선택할 수 있습니다. 프로필·동아리·임원·방 정보 저장에는 버전 검사를 적용하므로 다른 창에서 먼저 수정했다면 최신 정보를 다시 읽고 저장해야 합니다. 이름을 변경해도 동아리 ID에 연결된 계정·예약·벌점은 유지됩니다.

## 동아리방 배치와 이동

학생회관 3층 통합 배치도, 실외 컨테이너, 2층 확인 호실 목록을 제공합니다. 2층 전체의 위치·크기 도형은 제공하지 않으며 확인된 호실을 목록으로 나타냅니다. 배치도는 초기 자료와 관리자 변경을 조합한 정보이며 실측 도면을 의미하지 않습니다.

방을 선택해 연결 동아리 정보를 확인하고 **호실·배정 변경**에서 표시 이름·호실·연결 동아리를 수정합니다. 한 방에 최대 10개 동아리를 연결할 수 있습니다. 다른 방의 동아리를 선택하면 새 방으로 이동하고 기존 연결이 해제됩니다. 현재 방에서 선택 해제된 동아리는 `미배정`이 됩니다. 방 호실은 1~40자이며 다른 방과 중복될 수 없습니다. 저장은 배치 버전을 확인하고 동아리 호실·연결·감사 기록을 함께 반영합니다.
