# 장소 예약

승인된 동아리 대표 계정의 장소대여 이용자가 날짜·장소·연속 시간대를 골라 예약합니다. 메인 관리자는 오픈 상태와 일정을 관리하고 사유를 남겨 추가승인 예약을 등록할 수 있습니다.

## 시간과 상태 기준

| 항목 | 현재 규칙 |
|---|---|
| 장소 | 심정실·진리실·창의실 |
| 오전·오후 초반 | 09:00~15:00, 1시간 단위 `H9`~`H14` |
| 오후 타임 | A 15:00~17:00, B 17:00~19:00, C 19:00~21:00 |
| 시간 선택 | 중복 없이 연속 선택. 15시 전 선택분은 한 예약에서 최대 4시간 |
| 제한일 | 금요일·토요일·일요일 또는 등록한 공휴일에는 동아리별 하루 활성 예약 합계 최대 4시간 |
| 지난 시간 | 지난 날짜·이미 시작한 시간의 신규 예약 불가 |
| 일반 예약 | 해당 날짜·장소가 오픈되어 있어야 함 |
| 추가승인 | 사유 필수. 오픈 여부·제한일의 하루 총 4시간 제한은 우회하지만 중복·지난 시간·선택 시간 검증은 유지 |
| 예약 상태 | `APPROVED` 확정, `OVERRIDE` 추가승인, `CANCELLED` 취소, `DELETED` 목록 삭제 |

기준 시각은 서버의 한국시간입니다. 브라우저는 서버 시각에 경과 시간을 더해 현재 시각과 오픈 카운트다운을 표시하고, 실제 접수 여부는 저장 시점에 서버가 판정합니다. 추가승인의 `force` 값도 `resolveSlots`의 15시 전 최대 4시간 검사를 해제하지 않습니다.

## 예약하기

1. **대여 → 장소대여**에서 공지를 확인하고 승인된 대표 계정으로 로그인합니다.
2. 날짜·장소·연속 시간대를 선택합니다. 선택한 구간의 합계와 시작·종료를 확인합니다.
3. 대표자 이름(최대 40자), 전화번호(숫자 10~11자리), 선택 메모(최대 500자)를 입력합니다. 동아리는 로그인 정보로 결정됩니다.
4. 이용규정에 동의합니다. 해당 날짜에 동방점검이 등록되어 있으면 참석 동의도 필요합니다.
5. **예약 확정하기**를 누른 뒤 성공 화면의 날짜·장소·시간을 확인합니다. 이후 **우리 동아리 예약**에서 조회·취소합니다.

동일 요청 키로 재전송하면 내용이 같은 활성 예약의 결과를 돌려줍니다. 다른 사용자가 먼저 선점하면 저장을 거절하고 시간표를 다시 불러옵니다. 실패 알림이 뜨면 최신 가능 시간을 확인하세요. 시작한 예약은 사용자 화면에서 취소할 수 없으므로 관리자에게 요청해야 합니다.

## 오픈·마감과 자동 오픈

**관리자 → 장소대여 → 예약 오픈**에서 기간과 개별 추가 날짜를 합쳐 최대 93일, 하나 이상의 장소를 선택합니다. 기본적으로 오픈 정보가 없는 날짜·장소는 마감입니다.

- **지금 오픈·마감:** 활성 예약이 있는 대상이 포함되면 일괄 마감 전체를 거절합니다. 성공한 수동 변경은 해당 대상의 자동 오픈 연결도 제거합니다.
- **시간 지정 자동 오픈:** 대여 날짜와 접수 시작 한국시간을 따로 지정합니다. 시작 시각은 현재보다 미래이고 첫 대여 대상 날짜 또는 그 이전이어야 합니다. 이미 오픈되었거나 다른 자동 오픈이 있는 대상은 덮어쓰지 않습니다.
- **자동 오픈 취소:** 시작 시각 전 대기 설정만 취소합니다. 시각이 지난 뒤 닫으려면 지금 오픈·마감을 사용합니다.

예약 접수 시 DB에서 오픈 시각을 비교하므로 관리자 PC를 켜둘 필요가 없습니다. 자동 오픈 목록은 오늘 이후 대상이 남은 설정을 30건씩 표시합니다.

근거: [오픈 UI](../../src/scheduled-openings.tsx), [자동 오픈 처리](../../lib/scheduled-openings.mjs), [오픈 판정](../../lib/opening-time.mjs), [자동 오픈 테스트](../../tests/scheduled-openings.test.mjs).

## 예약 목록과 정렬

메인 관리자는 조회 기간·검색·상태 필터와 대여 날짜 빠른/늦은 순, 신청 시각 오래된/최신 순 정렬을 사용합니다. 서버가 정렬한 앞 1,000건을 표시하며 초과 시 기간을 좁히라는 안내가 나옵니다. 신청 시각은 초 단위 한국시간입니다. CSV는 별도 내보내기로 기간 전체를 대여 날짜·시작 시간 순으로 반환하며 목록 검색·상태 필터를 그대로 적용하지 않습니다.

**내 동아리**의 예약 내역은 자신의 삭제되지 않은 예약을 과거·취소 포함 대여 날짜 빠른 순으로 30건씩 보여줍니다. **장소대여 → 우리 동아리 예약**은 별도 목록이며 날짜 늦은 순으로 조회하고 시작 전 활성 예약을 취소합니다.
