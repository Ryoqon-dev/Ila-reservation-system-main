# 동시 로그인 · 장소대여 단독 이용 업데이트

현재 누적 버전 1.6.0 / portal-catalog-rooms-v1 (최신 변경: [PORTAL_LAYOUT_UPDATE.md](../../06-uiux/history/PORTAL_LAYOUT_UPDATE.md)) / 2026-10-26

## 달라지는 이용 방식

- 같은 동아리 계정으로 PC·휴대폰 등 여러 곳에서 함께 로그인할 수 있습니다.
- **먼저 로그인한 한 접속자**에게 장소대여 이용 권한을 줍니다. 장소대여 메뉴에 먼저 들어간 순서가 아닙니다. 내 동아리 관리만 보고 있어도 첫 로그인자의 권한은 유지됩니다.
- 다른 접속자가 장소대여 메뉴를 누르면 **“장소 대여 메뉴는 한 명만 입장 가능합니다.”** 팝업을 표시합니다. 첫 로그인자의 예약·취소 중복 처리를 막기 위해 장소 예약과 우리 동아리 예약 모두 같은 제한을 적용합니다.
- 다른 접속자도 내 동아리 관리에서 사진·동방점검 벌점, 사유, 총합, 가장 빠른 예약을 확인할 수 있습니다.
- 첫 로그인자가 로그아웃하면 해당 권한을 반납합니다. 남아 있는 활성 접속 중 먼저 로그인한 사람이 다음 접속 확인에서 이어받습니다. 나중 로그인자가 먼저 확인 버튼을 눌러도 순서를 건너뛰지 않습니다.
- 화면이 보이는 동안 1분마다 접속을 확인합니다. 창 종료·통신 단절·휴대폰 백그라운드 등으로 확인이 끊기면 마지막 접속 확인 후 약 3분에 권한이 만료됩니다. 다른 접속자의 자동 확인까지 최대 약 1분이 더 걸릴 수 있으며, 메뉴 클릭이나 ‘이용 권한 다시 확인’으로 바로 확인할 수 있습니다. 탭 전환·네트워크 지연으로 확인이 중단된 경우도 같습니다.
- 기존 담당자가 다시 화면을 열어도 새 담당자가 이용 중이면 권한을 빼앗지 않습니다. 예약 작성 중이었다면 다시 권한을 얻은 후 진행해야 합니다. 서버에 확정된 예약은 유지됩니다.
- 같은 브라우저의 여러 탭은 쿠키를 공유하므로 한 로그인으로 취급합니다. 서로 다른 사용자를 구별하려면 다른 기기·브라우저·브라우저 프로필을 사용하세요.
- 로그아웃은 해당 로그인만 종료합니다. 아이디·비밀번호 변경, 관리자 계정 수정·이용 정지·삭제, 동아리 비활성화 시에는 동아리의 모든 로그인을 종료합니다. 로그인 유효기간은 최대 8시간입니다.
- 관리자 장소대여 관리·추가승인에는 이 동아리별 제한을 적용하지 않습니다.

## 기존 운영 사이트에 적용

이번 ZIP은 이전 계정·공지·벌점·데이터 관리 업데이트까지 포함한 누적본입니다.

1. ZIP을 **기존 배포 폴더와 다른 새 폴더**에 압축 해제합니다. 기존 폴더를 덮어쓰거나 삭제하지 마세요.
2. 새 폴더 안 `ila-free-hosting`에서 **APPLY_SITE_UPDATE.cmd**를 두 번 클릭합니다.
3. “기존 배포 폴더 경로”에 예전에 실제로 배포한 `wrangler.json`이 있는 폴더를 입력합니다. 예전 경로를 그대로 사용했다면 다음과 같습니다.

```text
C:\Users\김주영\Desktop\36대 총동 파일\ILA_Free_Hosting\ila-free-hosting
```

4. DB·설정·키·이전 소스 백업 → 수정 파일 적용 → 필요한 DB 마이그레이션 → 같은 사이트 배포가 차례로 진행됩니다. 계속 여부를 물으면 `y`를 입력합니다.
5. **“동아리 통합 관리 업데이트 및 배포 완료”**가 나오는지 확인합니다. 현재 공개/비공개 설정과 주소를 유지합니다.
6. PC는 Ctrl+F5, 휴대폰은 새 시크릿 창으로 열어 새 화면을 불러옵니다. 이미 열린 구버전 화면은 새로고침해야 합니다.

0007 마이그레이션은 기존 유효한 동아리 로그인을 새 세션 테이블로 이관합니다. 예약·벌점·계정 비밀번호·공지·이미지를 초기화하지 않습니다. 백업에는 비밀 키가 있으니 외부에 공유하지 마세요. 업데이트를 실행하기 전에는 운영 사이트에 반영되지 않습니다.

## 적용 후 간단 확인

1. PC에서 동아리 계정에 로그인하고 장소대여를 엽니다.
2. 휴대폰에서 같은 계정으로 로그인합니다. PC 접속이 유지되는지 확인합니다.
3. 휴대폰에서 내 동아리 관리의 벌점·일정이 보이는지 확인합니다.
4. 휴대폰에서 장소대여를 누르면 안내 팝업이 나오는지 확인합니다.
5. PC에서 로그아웃합니다. 휴대폰에서 장소대여를 다시 누르면 예약·내역·취소 메뉴가 열립니다.
6. 연결 종료도 시험하려면 PC를 다시 첫 접속자로 로그인한 후 창을 닫고, 휴대폰에서 약 3분 후 권한을 다시 확인합니다.

## 보안과 검증 범위

팝업뿐 아니라 서버에서 로그인·동아리 승인·소속·장소대여 권한을 확인합니다. 직접 주소, 기존 예약 조회/확인서 API, 예약 신청·취소도 제한합니다. 저장 직전에 권한이 철회되면 예약·취소를 실행하지 않습니다. 첫 로그인자 선정·갱신·인계는 DB의 원자적 처리로 중복 담당자를 방지합니다. 클라이언트에서 임의로 권한을 보내도 신뢰하지 않습니다.

추가 외부 인증 서비스나 유료 서비스를 도입하지 않습니다. 접속 확인은 서버 요청과 D1 읽기·쓰기를 사용하므로 접속 기기 수와 이용 시간에 따라 사용량은 늘어납니다. 무료 한도 무제한 보장은 아닙니다.

자동 테스트, 정적 UI 렌더링, TypeScript, 프로덕션 빌드 및 로컬 Worker·D1 동작을 검사합니다. 사용자의 실제 Cloudflare 운영 계정 배포나 실제 PC·휴대폰 브라우저 조작을 대신 수행한 것은 아닙니다.
