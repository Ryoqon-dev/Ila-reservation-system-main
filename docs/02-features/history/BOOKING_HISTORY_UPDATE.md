# 예약 내역·관리자 예약 정렬 업데이트

버전 1.6.1 / booking-history-order-v1 / 2026-10-26

## 바뀐 기능

### 내 동아리 관리 → 예약 내역

‘가장 빠른 장소대여 일정’ 한 건 대신 로그인한 동아리의 전체 예약 내역을 표시합니다. 대여 날짜, 같은 날짜에서는 시작 시간이 빠른 순으로 정렬합니다. 장소, 날짜·시간, 예약 확정·추가승인·취소 상태와 이용 예정·이용 중·이용 완료 여부를 확인할 수 있습니다.

지난 예약과 취소 내역도 포함하고 관리자가 목록에서 삭제한 기록은 표시하지 않습니다. 내역이 많으면 30건씩 ‘이전 예약’·‘다음 예약’으로 확인합니다. 벌점 내역의 페이지·종류 선택과 예약 페이지는 각각 동작합니다. 새로고침이나 화면 복귀 시 예약·취소 상태를 다시 불러옵니다.

예약번호·예약코드·확인서 버튼은 표시하지 않습니다. 예약 취소는 기존과 같이 대여 → 장소대여 → 우리 동아리 예약에서 합니다. 여러 기기에서 내 동아리 관리의 예약 내역을 함께 볼 수 있고, 장소대여와 취소는 먼저 로그인한 접속자에게 부여되는 기존 이용 권한을 유지합니다.

### 관리자 → 장소대여 시스템 관리 → 예약 목록

검색창 옆 ‘예약 정렬 기준’에서 다음 네 가지를 선택합니다.

| 정렬 기준 | 순서 |
|---|---|
| 대여 날짜 · 빠른 순 | 실제 대여 날짜·시작 시간이 이른 예약부터. 기본값입니다. |
| 대여 날짜 · 늦은 순 | 실제 대여 날짜·시작 시간이 늦은 예약부터 |
| 신청 시각 · 오래된 순 | 예약 신청이 먼저 등록된 예약부터 |
| 신청 시각 · 최신 순 | 예약 신청이 나중에 등록된 예약부터 |

각 예약에 신청 시각을 초 단위 한국시간으로 표시합니다. 신청 시각은 취소나 정렬 변경으로 덮어쓰지 않습니다. 같은 시각인 기록은 날짜·시작 시간·내부 식별자로 순서를 고정합니다. 날짜 조회 범위·검색·상태 필터와 사진 확인·취소·추가승인은 그대로 이용합니다.

정렬은 서버가 조회 기간 전체에 먼저 적용합니다. 기존의 화면 최대 1,000건 제한을 넘으면 선택한 순서의 앞 1,000건과 안내 문구를 표시하므로 기간을 좁혀 확인하세요. CSV는 기존 방식대로 조회 기간 전체를 대여 날짜순으로 내보냅니다.

## 기존 운영 사이트에 적용

1. 새 ZIP을 **기존 배포 폴더와 다른 새 폴더**에 압축 해제합니다.
2. 새 폴더 안 `ila-free-hosting`의 **APPLY_SITE_UPDATE.cmd**를 실행합니다.
3. 기존 `wrangler.json`과 `.secrets/runtime.json`이 있는 실제 배포 폴더 경로를 입력합니다. 예전 경로를 그대로 사용했다면 다음과 같습니다.

```text
C:\Users\김주영\Desktop\36대 총동 파일\ILA_Free_Hosting\ila-free-hosting
```

4. 기존 운영 DB·설정·키·소스를 백업한 후 파일 적용과 필요한 이전 마이그레이션, 같은 주소 배포가 진행됩니다. 계속 여부를 물으면 `y`를 입력합니다.
5. ‘동아리 통합 관리 업데이트 및 배포 완료’를 확인하고 PC에서는 Ctrl+F5, 모바일에서는 새 시크릿 창으로 다시 엽니다.

누적 업데이트이며 1.6.0의 안내·대여 목록·공지·임원 연락처·배치도도 포함합니다. 이번 1.6.1은 기존 테이블을 조회하는 변경으로 별도의 새 마이그레이션은 없습니다. 기존 예약·계정·벌점·보안 키·사이트 설정과 공개/비공개 설정을 유지합니다. 기존 폴더와 `backups`는 삭제하지 마세요. 백업에는 보안 정보가 포함되므로 공유하지 마세요.

파일을 받는 것만으로 운영 사이트가 바뀌지는 않습니다. 위 업데이트를 실행해야 적용됩니다.

## 적용 후 확인

- 동아리 계정으로 내 동아리 관리에 들어가 ‘예약 내역’에서 여러 예약의 날짜·시간 순서와 취소 상태, 다음 페이지를 확인합니다.
- 관리자 예약 목록에서 신청 시각과 대여 날짜의 두 기준을 바꾸며 카드 순서와 신청 시각 표시를 확인합니다.
- PC와 휴대폰에서 검색·상태 필터·예약·취소·추가승인이 기존처럼 동작하는지 확인합니다.
