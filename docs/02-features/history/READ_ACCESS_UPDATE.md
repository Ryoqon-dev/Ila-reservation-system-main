# 1.10.1 예약 조회 계정·기간제 링크·시간표 업데이트

1.10.1은 링크 자체의 만료 기간을 최대 365일로 늘린 누적 업데이트입니다. 기존 1.10.0에 적용하면 DB 구조 변경이 없습니다. 기존 예약·동아리·대표 계정·벌점·사이트 설정·사진 상태·자동 오픈·보안 키와 공개 범위를 유지합니다.

## 적용

1. ZIP을 기존 배포 폴더와 다른 새 폴더에 압축 해제합니다.
2. 새 폴더의 **APPLY_SITE_UPDATE.cmd**를 실행합니다.
3. 실제로 배포하던 `wrangler.json`·`.secrets/runtime.json`·`node_modules`가 있는 기존 폴더 경로를 입력합니다.
4. 기존 DB 백업 암호와 키 보관용 암호를 서로 다르게 입력합니다. 암호화 백업과 소스 보관을 먼저 하고, 아직 적용하지 않은 마이그레이션만 같은 DB에 준비한 뒤 같은 Worker에 배포합니다. 백업 실패 시 파일 교체·DB 변경 전에 중단합니다.
5. 완료 후 사이트를 Ctrl+F5로 다시 불러오고 메인 관리자 계정으로 로그인합니다. 이전 보안 전환을 적용하지 않았다면 SECURITY_UPDATE.md의 누적 전환·인증앱 등록도 함께 필요합니다.

새 DB 생성·서버 초기 설정·공개 전환 명령을 다시 실행하지 않습니다. 운영 계정에 직접 접근하지 않았으므로 ZIP 제공만으로 운영 사이트에 반영되지는 않습니다.

## 메인 관리자 사용법

**관리자 → 장소대여 시스템 관리 → 예약 목록** 아래에 두 개의 접이식 영역이 있습니다.

- **예약 시간표**: 기본은 접힘입니다. 펼치면 한국시간 기준 오늘을 선택합니다. 날짜를 바꾸면 해당 하루의 확정·추가승인을 09:00~21:00 시간축과 3개 장소 열로 표시합니다. 취소·삭제는 제외합니다. 예약 블록에는 동아리명만 표시합니다. 기존 목록의 조회 기간·검색 필터와 별개이므로 목록에서 검색한 동아리만 시간표에 나오는 것은 아닙니다.
- **조회 계정·링크 관리**: 메인 관리자에게만 표시됩니다. 계정 추가·수정, 링크 발급·정지를 할 수 있습니다.

메인 관리자 예약 목록에는 신청자 전화번호가 전체 표시됩니다. 서브 관리자·기간제 링크의 API에는 전화번호·신청자 이름·메모·추가승인 사유·방 비밀번호·학번·확인코드 등을 보내지 않습니다.

상단 **관리자 오른쪽**에는 남은 로그인 시간이 분·초로 표시됩니다. 15분 미사용 또는 최대 8시간 중 먼저 도달하는 시각까지의 시간입니다. 관리자 조작 시 갱신되며, 자동 조회·초 표시만으로는 연장되지 않습니다. 다른 탭 활동은 서버에 확인한 후 반영합니다.

## 조회 전용 서브 관리자

1. 조회 계정·링크 관리 → **조회 계정**에서 표시 이름·아이디·10자 이상 비밀번호를 입력합니다.
2. 메인 관리자의 현재 비밀번호와 새 인증앱 코드(또는 남은 복구 코드)로 본인 확인 후 저장합니다. 이는 권한 발급자의 확인 절차이며, 부원이 접속할 때는 2차 인증을 요구하지 않습니다.
3. 부원은 기존 관리자 진입 화면에서 **조회 전용 서브 관리자**를 선택하고 아이디·비밀번호로 로그인합니다. 로그인 후 예약 목록 전용 화면이 열립니다. 같은 브라우저에 메인 관리자 접속이 남아 있었다면 해당 메인 세션을 해제하여 조회 전용으로 전환합니다.
4. 예약 목록·정렬·조회 기간과 하단 시간표만 이용할 수 있습니다. 예약 취소·추가승인·사진 변경·벌점·계정·사이트 설정·CSV는 이용할 수 없습니다. 조회 기간은 요청당 최대 31일, 목록은 100건씩 조회합니다.
5. 계정을 수정하거나 사용 허용을 해제하면 기존 세션이 회수됩니다. 비밀번호 원문 조회는 제공하지 않으며 새 비밀번호로 재설정합니다. 서브 관리자도 15분 미사용·최대 8시간 제한이 있고, 자동 조회는 미사용 시간을 연장하지 않습니다.

## 만료되는 링크

1. 조회 계정·링크 관리 → **만료 링크**에서 이름·고정 조회 날짜·허용 장소·만료 시각을 선택합니다.
2. 예약 조회 범위는 기존과 같이 최대 7일입니다. 링크 자체의 만료는 발급 시점부터 최대 **365일**이며, 한국시간 기준으로 시각을 직접 입력하거나 **1일·7일·30일·90일·1년** 버튼을 누릅니다. 기본은 약 24시간 뒤입니다. 기존에 발급한 링크의 만료일은 그대로이며, 더 긴 만료일이 필요하면 새로 발급합니다.
3. 메인 관리자의 현재 비밀번호와 새 2차 인증으로 발급합니다. 발급 직후 표시되는 주소를 복사해 보관합니다. 목록에는 인증값을 보여주지 않습니다. 응답을 받지 못해 주소를 확보하지 못했다면 해당 이름의 링크를 정지하고 새로 발급합니다.
4. 링크를 받은 사람은 별도 로그인 없이 지정한 날짜·장소의 예약 목록과 시간표만 봅니다. 링크를 다른 사람에게 전달하면 그 사람도 만료 전 접속할 수 있습니다. 열어 둔 접속은 최대 7일 유지되며, 링크가 여전히 유효하면 받은 주소를 다시 열 수 있습니다. 개인정보는 제외하며, 접속자 본인을 식별하는 기능은 아닙니다.
5. **정지**하면 이미 발급된 조회 세션도 다음 데이터 요청부터 차단됩니다. 열린 화면은 최대 1분 간격과 탭 복귀 시 권한을 다시 확인합니다. 만료 시각에는 화면을 해제합니다. 이미 확인·복사·캡처·다운로드한 내용은 회수할 수 없습니다.
6. 활성 링크는 최대 100개이며 관리 목록은 활성 우선 100건을 표시합니다. 토큰·세션 원문은 DB와 운영 기록에 저장하지 않습니다. 링크의 인증값은 URL fragment로 전달하고 진입 시 주소에서 제거한 후 동일 출처 POST로 제한 세션으로 교환합니다.

비공개 테스트 사이트에서는 기존 별도 접속 비밀번호도 계속 필요합니다. 링크가 사이트의 비공개 보호를 우회하지 않습니다.

## 시간표 이미지 저장

시간표를 펼친 뒤 **이미지 저장**을 누르면 브라우저에서 PNG를 만듭니다. 저장 직전에 해당 날짜의 예약과 권한을 다시 확인합니다. 동아리명·시간·장소·날짜만 직접 그리므로 전화번호가 있는 화면을 통째로 캡처하지 않습니다. 외부 이미지 생성·메일·문자 서비스와 별도 저장 공간을 사용하지 않습니다. PNG는 저장 시점의 목록이며, 이후 취소가 자동 반영되지는 않습니다. 긴 이름은 표 안에서 줄바꿈·스크롤 또는 텍스트 보기로 확인할 수 있습니다.

## 보안·검증 범위

권한은 버튼 표시뿐 아니라 서버 요청마다 확인합니다. 메인·서브·공유 쿠키와 테이블은 분리되어 있으며, 클라이언트의 role/admin 플래그로 권한을 얻을 수 없습니다. 서브 계정 변경·링크 발급·정지는 저장 시점의 메인 권한도 확인합니다. 로그인·토큰 교환에는 요청 제한을 적용합니다. 자세한 검사 결과와 운영 환경에서 남는 한계는 REVIEW.md에 있습니다.

유료 발송·인증 서비스를 추가하지 않았습니다. 기존 Workers·D1 무료 한도를 함께 사용하며 실제 운영 CPU·트래픽·무료 한도 충족은 운영 환경에서 별도로 확인해야 합니다.
