# 동아리 등록·수정 스크롤 개선

버전 1.7.1 / club-editor-dialog-v1 / 2026-10-26

현 동아리 관리에서 긴 목록과 입력 양식을 함께 내려야 했던 불편을 개선했습니다.

- 목록 상단의 **동아리 등록**을 누르면 별도 등록 팝업이 열립니다.
- 각 동아리 카드의 **동아리 정보 수정**을 누르면 해당 동아리의 수정 팝업이 바로 열립니다. 상세 정보 창과 배치도에서 누르는 수정도 같은 방식입니다.
- 팝업 안의 입력 내용만 스크롤합니다. 제목·닫기 버튼과 하단 저장·취소 버튼은 항상 표시합니다.
- 팝업을 열면 배경 목록의 스크롤을 잠그고, 닫으면 원래 목록 위치와 조작하던 버튼으로 돌아갑니다.
- 저장하지 않은 내용을 닫을 때 확인합니다. 저장 중에는 중복 저장과 닫기를 막고, 저장이 실패하면 입력을 유지합니다.
- PC와 모바일에서 같은 방식으로 이용합니다. 오른쪽에 항상 표시되던 긴 등록 양식 대신 목록을 넓게 표시합니다.

상태·기준일·분과·학번·회원 수·지도교수와 기존 계정·예약·벌점 등의 기능을 유지합니다. 새 DB 마이그레이션은 없습니다.

## 운영 사이트 적용

1. 새 ZIP을 기존 운영 폴더와 **다른 새 폴더**에 압축 해제합니다.
2. 새 폴더의 `ila-free-hosting` 안에서 **APPLY_SITE_UPDATE.cmd**를 실행합니다.
3. 기존 `wrangler.json`과 보안 키·배포 도구가 있는 실제 배포 폴더 경로를 입력합니다.
4. 기존 DB·설정·소스 백업, 파일 적용, 필요한 이전 마이그레이션과 같은 주소 배포가 진행됩니다. 계속 여부를 물으면 `y`를 입력합니다.
5. ‘동아리 통합 관리 업데이트 및 배포 완료’를 확인한 후 PC는 Ctrl+F5, 휴대폰은 새 시크릿 창에서 확인합니다.

이전 업데이트를 모두 포함하는 누적 파일입니다. 기존 공개 설정과 운영 데이터를 유지하며, 위 실행 과정을 거쳐야 운영 사이트에 반영됩니다.
