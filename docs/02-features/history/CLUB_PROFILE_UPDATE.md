# 동아리 상태·분과·운영 정보 업데이트

버전 1.7.0 / club-profile-divisions-v1 / 2026-10-26

## 동아리 정보 입력

관리자 → 현 동아리 관리 → 해당 동아리의 **동아리 정보 수정**을 누릅니다. 새 동아리는 오른쪽 ‘동아리 등록’ 양식을 사용합니다.

| 항목 | 입력 방법 |
|---|---|
| 동아리 상태 | 정동아리 / 준동아리 / 신규동아리 중 선택 |
| 상태 기준일 | 현재 상태를 지정한 날짜. 오늘 또는 지난 날짜를 선택 |
| 동아리 분과 | 공연분과 / 봉사분과 / 체육분과 / 교양/학술 분과 중 선택 |
| 회원 수 | 0 이상의 정수. 미확인 시 빈칸으로 유지 |
| 지도교수 이름 | 이름을 입력. 미확인 시 빈칸으로 유지 |
| 임원 학번 | 회장·부회장·총무마다 숫자 10자리. 앞의 0도 보존 |

기존 이름·호실·방 비밀번호와 회장·부회장·총무 이름·전화번호도 함께 편집할 수 있습니다. 저장하면 동아리 카드와 동아리 이름/배치도에서 여는 정보 창에 반영됩니다.

동아리 상태를 선택하면 기준일에 오늘 날짜를 제안합니다. 실제 지정일이 이전 날짜면 수정한 후 저장하세요. 회원 수·지도교수·연락처 등 다른 항목만 바꾸면 저장된 상태 기준일을 유지합니다. 미래 기준일이나 잘못된 날짜는 저장하지 않습니다.

기존 동아리의 상태·분과·학번·회원 수·지도교수는 임의로 추정하지 않습니다. 미지정·미등록으로 시작하므로 실제 자료를 확인한 뒤 입력하세요. 학번은 선택 입력이지만, 입력할 경우 하이픈·공백·문자 없이 정확히 숫자 10자리여야 합니다.

정동아리·준동아리·신규동아리는 동아리 분류입니다. 가입 승인 대기·정식 대표 계정 등 로그인 계정의 승인 상태는 기존 방식대로 별도로 관리합니다. 동아리 분류 변경만으로 대표 계정을 승인하거나 예약 권한을 바꾸지 않습니다.

## 상태·분과별 목록 보기

현 동아리 관리의 배치도 아래에 다음 순서로 집계가 나타납니다.

1. 등록 동아리 / 가입 승인 대기 / 정식 대표 계정
2. 정동아리 / 준동아리 / 신규동아리
3. 공연분과 / 봉사분과 / 체육분과 / 교양/학술 분과

집계 카드를 누르면 해당 조건의 목록이 나타납니다. 예를 들어 ‘정동아리’와 ‘공연분과’를 함께 선택하면 공연분과 정동아리만 볼 수 있습니다. 선택한 카드를 다시 누르면 해당 조건만 해제합니다. **등록 동아리** 또는 **필터 초기화**를 누르면 모든 상태·분과 선택을 해제합니다.

동아리명·호실·아이디 검색을 함께 사용할 수 있습니다. 각 집계 숫자는 검색어와 다른 필터에 영향받지 않는 전체 활성 동아리 기준입니다. ‘비활성 동아리 포함’을 선택하면 비활성 동아리도 집계와 목록에 포함합니다. 기준일·회원 수·지도교수와 임원 학번은 각 카드에서 확인합니다.

## 기존 운영 사이트에 적용

1. 새 ZIP을 **기존 배포 폴더와 다른 새 폴더**에 압축 해제합니다.
2. 새 폴더 안 `ila-free-hosting`의 **APPLY_SITE_UPDATE.cmd**를 실행합니다.
3. 기존 `wrangler.json`과 보안 키·배포 도구가 있는 실제 배포 폴더 경로를 입력합니다. 예전 폴더를 그대로 사용했다면 다음과 같습니다.

```text
C:\Users\김주영\Desktop\36대 총동 파일\ILA_Free_Hosting\ila-free-hosting
```

4. 운영 DB·설정·보안 키·기존 소스 백업 → 파일 적용 → 필요한 마이그레이션 → 같은 주소 배포가 진행됩니다. 계속 여부를 물으면 `y`를 입력합니다.
5. ‘동아리 통합 관리 업데이트 및 배포 완료’를 확인하고 PC는 Ctrl+F5, 모바일은 새 시크릿 창에서 확인합니다.

0009 마이그레이션은 동아리 운영 정보를 위한 테이블·조회 인덱스를 추가합니다. 기존 예약·계정·벌점·공지·이미지·배치와 공개/비공개 설정을 유지합니다. 임원 학번은 기존 임원 정보에 함께 저장합니다. 이전 버전의 업데이트도 모두 포함하며, 파일을 받는 것만으로 운영 사이트에 반영되지는 않습니다.

## 저장·개인정보 처리

동아리 운영 정보와 임원 학번은 관리자 인증 후 조회·수정합니다. 일반 안내·동아리 회원 API와 현재 CSV 내보내기에는 포함하지 않습니다. 전체 복구용 DB 백업에는 해당 정보도 포함되므로 기존 `backups` 폴더를 외부에 공유하지 마세요.

여러 관리자 화면에서 같은 동아리를 동시에 수정하면 먼저 저장된 운영 정보를 기준으로 오래된 수정본을 차단합니다. 충돌 안내가 나오면 목록을 새로고침하고 다시 수정하세요. 저장 도중 DB 오류가 나면 동아리·운영 정보·임원·방 배정 변경을 함께 되돌립니다.
