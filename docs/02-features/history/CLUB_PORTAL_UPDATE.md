# 동아리 통합 관리 업데이트

현재 ZIP: 1.6.0 / portal-catalog-rooms-v1 (최신 변경: [PORTAL_LAYOUT_UPDATE.md](../../06-uiux/history/PORTAL_LAYOUT_UPDATE.md))

**최신 적용·데이터 관리·학기 초기화 안내는 DATA_MANAGEMENT_UPDATE.md를 먼저 읽으세요.** 아래는 이전 화면 개편 기능 안내입니다.

기존 대표 계정·사이트 설정 업데이트를 모두 포함한 누적 수정본입니다. 운영 사이트에는 아래 업데이트 도구를 실행해야 반영됩니다.

## 운영 사이트에 적용하기

1. 이번 ZIP을 **기존 배포 폴더와 다른 새 폴더**에 압축 해제합니다. 기존 폴더는 삭제하거나 덮어쓰지 마세요.
2. 새 폴더 안 `ila-free-hosting`의 **APPLY_SITE_UPDATE.cmd**를 더블 클릭합니다. 다른 CMD를 추가로 실행할 필요가 없습니다.
3. “기존 배포 폴더 경로”에 **예전에 실제 배포했던 폴더**를 입력합니다. 새 압축 해제 폴더를 입력하면 안 됩니다.
4. 해당 기존 폴더에는 실제 `wrangler.json`, `.secrets/runtime.json`, `node_modules`가 있어야 합니다. `wrangler.example.json`만 있는 폴더는 해당하지 않습니다. 비밀번호·보안 키 파일을 다른 사람에게 보내지 마세요.
5. 도구는 운영 DB·보안 키·이전 파일 백업 → 새 파일 복사 → 필요한 마이그레이션 → 같은 주소 배포 순서로 진행합니다. 마이그레이션 확인 질문이 나오면 `y` 후 Enter를 누릅니다.
6. **“동아리 통합 관리 업데이트 및 배포 완료”**가 표시되면 사이트에서 PC는 Ctrl+F5, 모바일은 새 시크릿 창으로 확인합니다.

예전부터 폴더를 옮기지 않았다면 기존 경로는 다음과 같습니다. 실제 `wrangler.json`이 있는지 먼저 확인하세요.

```text
C:\Users\김주영\Desktop\36대 총동 파일\ILA_Free_Hosting\ila-free-hosting
```

업데이트는 운영 DB ID, Worker 이름, 보안 키와 기존 공개·비공개 설정을 유지합니다. 별도 공개 전환 명령을 실행할 필요가 없습니다. 새로운 유료 저장소도 추가하지 않습니다. 백업에는 DB와 키가 들어 있으므로 기존 폴더의 `backups`는 외부에 공유하지 마세요. DB 백업이 실패하면 파일 교체를 시작하지 않고, 마이그레이션 실패 시 배포를 진행하지 않습니다.

## 1.3.2 예약 표시 정리

예약 완료 안내는 날짜·장소·시간과 조회/취소 경로만 보여줍니다. 확인서 다운로드 버튼, 예약 확인코드, 예약번호를 표시하지 않습니다. 우리 동아리 예약 내역에서도 확인서 다운로드 버튼과 예약번호를 숨기고 예약 상태·대표자·예약 취소를 유지합니다. 내 동아리 관리의 다음 예약에서도 내부 예약번호를 숨깁니다.

예약번호는 내부 식별자로 계속 사용하며 DB 기록·예약 취소 권한·중복 예약 방지·관리자 예약 목록은 유지합니다. 새 DB 마이그레이션은 추가하지 않습니다.

## 달라진 화면과 사용법

- 첫 화면의 두 메뉴: **장소대여 / 내 동아리 관리**. 관리자 입구는 우측 상단에 있습니다.
- 장소대여 또는 내 동아리 관리를 선택했을 때 로그인이 필요하면 대표 계정 로그인 화면이 나타납니다. 로그인 후 선택한 메뉴가 열립니다. 같은 브라우저에서는 두 메뉴 사이를 다시 로그인하지 않고 이동합니다.
- 상단 메뉴: **장소대여 / 내 동아리 관리(계정 아이디) / 관리자**. 로그인 전에는 ‘내 동아리 관리’로 표시됩니다. 별도 계정 페이지는 제거했고 계정 변경·로그아웃은 내 동아리 관리 화면의 계정 배너에서 이용합니다. 이전 `?view=account` 링크도 내 동아리 관리로 연결됩니다.
- 장소대여의 **우리 동아리 예약** 탭에서 조회·취소를 이용합니다. 하단의 중복된 ‘내 예약 조회·취소’ 입력 폼은 제거했습니다. 기존 예약 기록은 유지됩니다.
- 내 동아리 관리: 사진 미제출 벌점, 동방점검 벌점, 총합 벌점, 벌점 날짜·사유 및 가장 빠른 장소대여 일정. 벌점 상세는 전체/사진 미제출/동방점검으로 구분하고 30건씩 조회합니다.
- 관리자 → 현 동아리 관리에서 **가입 승인 대기 / 정식 대표 계정** 숫자 카드를 누르면 해당 상태만 표시됩니다. ‘등록 동아리’를 누르면 전체로 돌아갑니다. 상태 카드를 누를 때 이전 검색어를 초기화하며, 상태 선택 후 검색도 가능합니다. ‘비활성 동아리 포함’은 카드 숫자와 목록에 함께 적용됩니다.

## 첫 화면 공지 ON/OFF

1. 관리자 로그인 → **사이트 설정 → 첫 화면 공지**로 이동합니다.
2. 제목과 내용을 입력하고 ‘첫 화면에 공지 표시’를 켭니다.
3. **저장 전 미리보기**로 확인한 뒤 **변경사항 저장**을 누릅니다.
4. 첫 화면을 열면 공지가 팝업으로 나타납니다. 로그인 전에도 보이는 공개 공지이므로 공개할 내용만 작성하세요.
5. 숨기려면 스위치를 OFF로 바꾸고 저장합니다. 작성한 제목·내용은 유지됩니다.

첫 화면 공지는 예약 화면의 이용 안내 팝업과 별개입니다. 첫 화면 공지만 수정하거나 끄고 켜도 기존 예약 이용 안내의 읽음 상태에는 영향을 주지 않습니다. 첫 화면 공지는 확인 버튼·닫기·Esc로 닫을 수 있습니다. 닫은 후 같은 페이지에서 메뉴를 오가는 동안은 다시 열지 않고, 새로고침·다시 접속하면 표시합니다. 제목이나 내용을 바꾸면 새 공지를 표시합니다. 새로 접속·새로고침하면 반영되고, 열린 화면은 창에 다시 포커스할 때 일정 간격으로 갱신합니다. 실시간 알림 전송 기능은 아닙니다.

## 벌점·다음 예약 기준

- 1.4부터 벌점 합계는 **마감되지 않은 현재 학기**, 관리자가 실제 적용한 유효 기록 기준입니다. 취소된 벌점은 합계와 사용자 상세 목록에서 제외합니다.
- 사진 미제출은 관리자가 예약 관리에서 확인 후 적용하거나, **관리자 → 동방점검 관리 → 동방점검·사진 벌점 입력**에서 직접 등록할 수 있습니다. 벌점 종류를 사진 미제출로 선택하고 동아리·발생 날짜·차감 점수·사유를 입력합니다. 기본 점수는 10점이며 관리자가 1~1000점으로 입력할 수 있습니다. 미확인 사진을 자동으로 벌점 처리하지 않습니다.
- 화면에는 감점으로 표시합니다. 예: 사진 -10점 + 점검 -7점 = 총합 -17점.
- 가장 빠른 일정은 로그인한 동아리의 확정·추가승인 예약 중 **종료되지 않은 일정**입니다. 이용 중인 예약이 있으면 우선 표시하고 ‘현재 이용 중’으로 구분합니다. 취소·삭제·이미 끝난 예약은 제외합니다. 기준 시각은 서버의 한국 시간입니다.
- 등록된 일정이 없으면 ‘예정된 장소대여가 없습니다’, 벌점이 없으면 0점과 빈 내역을 표시합니다.
- 다른 동아리 ID를 요청에 넣어도 조회 소속은 서버에서 로그인 계정으로 결정합니다. 승인 대기·정지·만료 계정은 조회할 수 없습니다. 동방 비밀번호, 계정 비밀번호, 다른 동아리 정보는 이 화면에서 제공하지 않습니다.

사진 벌점은 동아리별 같은 날짜에 한 번만 적용합니다. 예약 관리의 사진 벌점과 수동 입력이 같은 일별 키를 사용하므로 중복으로 더하지 않습니다. 이미 등록된 날짜를 수동 입력하면 409 안내와 함께 거절합니다. 예약 관리 바로가기는 기존 수동 입력 사유·점수를 덮어쓰지 않습니다. 날짜·점수·사유를 잘못 입력했으면 관리자 상세 내역에서 취소한 후 다시 등록하세요. 취소된 같은 날짜의 사진 기록은 정정한 내용으로 재활성화됩니다. 동방점검 벌점은 기존처럼 여러 건 등록할 수 있습니다.

## 데이터 보존과 적용 후 확인

0005 마이그레이션은 벌점 조회 인덱스만 추가합니다. 기존 계정·예약·벌점·사이트 설정을 삭제하지 않습니다. 아직 적용하지 않은 이전 버전의 0003/0004가 있다면 함께 적용됩니다. 기존 사이트 설정에는 첫 화면 공지 OFF가 기본값으로 추가됩니다.

운영 적용 후 PC와 휴대전화에서 다음을 확인하세요.

1. 관리자 상태 카드 클릭 → 해당 계정만 표시 → 가입 승인 후 대기 목록에서 제외.
2. 첫 화면 공지 ON 저장 → 새 창에서 표시 → OFF 저장 → 숨김.
3. 로그아웃 후 장소대여/내 동아리 관리 각각 클릭 → 로그인 → 원래 선택한 메뉴 표시.
4. 내 동아리 관리에서 기존 관리자 벌점 합계·사유 및 다음 예약과 대조.
5. 우리 동아리 예약에서 예약 취소 → 내 동아리 관리에서 다음 일정 갱신.
6. 상단 메뉴가 세 개이고, 로그인 아이디가 내 동아리 관리 괄호 안에 표시되는지 확인.
7. 수동 사진 벌점 입력 → 내 동아리 관리의 사진 점수·총합·사유 반영 → 같은 날짜 중복 입력 거절.
8. 공지가 첫 화면 팝업으로 표시되고 확인·닫기·Esc로 닫히는지, OFF 저장 시 숨겨지는지 확인. 긴 계정 아이디·긴 공지는 휴대전화에서도 확인.

개발 검증은 자동 API·권한·데이터 보존 검사, 타입 검사, 정적 화면 렌더링 및 로컬 Worker+D1 실행으로 수행합니다. 실제 운영 배포 및 실제 모바일·PC 브라우저 클릭 검증을 수행했다는 뜻은 아닙니다.
