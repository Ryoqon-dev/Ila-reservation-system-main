# 데이터·사용량 관리와 학기 벌점 초기화

현재 누적 버전 1.6.0 / portal-catalog-rooms-v1 / 2026-10-26
데이터 관리 최초 도입: 1.4.0

## 1.5.1 통계 연결 오류 수정

계정 ID·토큰이 올바르더라도 ‘Cloudflare 통계에 연결하지 못했습니다’가 표시되는 코드 오류를 수정했습니다. 이전 코드가 사용한 redirect: error 옵션은 Cloudflare Workers에서 지원하지 않아 요청 전 TypeError가 발생했습니다. redirect: manual로 바꾸고 3xx 응답은 명시적으로 거절해 토큰이 다른 주소로 전달되지 않도록 했습니다. 시간 초과와 읽을 수 없는 응답도 구별해 안내합니다.

이 버전은 데이터·계정·설정·동시 로그인·장소대여 권한 기능을 모두 포함한 누적 수정본입니다. 새 폴더에 압축 해제 → APPLY_SITE_UPDATE.cmd 실행 → 기존 wrangler.json이 있는 실제 배포 폴더 입력 순서로 적용하세요. 같은 주소와 공개 설정을 유지하며 기존 백업·마이그레이션·배포 절차를 사용합니다. 이번 수정 자체에는 새 DB 마이그레이션이 필요하지 않습니다.

‘업데이트 및 배포 완료’를 확인한 뒤 사이트를 새로고침하고, 기존에 발급한 Account Analytics 읽기 전용 토큰으로 조회 연결을 다시 저장하세요. 이 오류 때문에 토큰을 새로 발급할 필요는 없습니다. 토큰이 이미 만료·폐기되었거나 권한이 다르다면 별도 수정이 필요합니다. 토큰 원문은 채팅에 보내지 마세요.

실제 로컬 Workers의 fetch API와 모의 통계 서버를 연결해 성공 응답과 리디렉션 차단을 검증했습니다. 사용자 토큰·Cloudflare 운영 계정으로 실제 통계를 조회한 것은 아닙니다.


## 운영 사이트 업데이트

1. 이번 ZIP을 기존 배포 폴더와 **다른 새 폴더**에 압축 해제합니다.
2. 새 폴더의 `APPLY_SITE_UPDATE.cmd`를 실행합니다.
3. 실제 `wrangler.json`, `.secrets/runtime.json`, `node_modules`가 있는 **기존 배포 폴더** 경로를 입력합니다. 새 압축 해제 폴더나 예제 설정 파일을 선택하지 마세요.
4. 기존 DB·설정·키·소스 백업 후 추가 마이그레이션과 같은 주소 배포를 진행합니다. 확인 질문이 나오면 `y`와 Enter를 누릅니다.
5. 완료 후 PC Ctrl+F5 또는 모바일 새 창으로 접속합니다.

업데이트 자체로 예약·계정·벌점을 삭제하거나 초기화하지 않습니다. 기존 공개/비공개 설정, DB ID, 암호화 키도 유지합니다. 이전 누적 업데이트를 포함하므로 이번 CMD 한 개만 실행하면 됩니다.

## 관리자 → 데이터·사용량 관리

### 용량·사용량

- 현재 DB 저장 용량(MB), 무료 기준 500MB 대비 비율, 예약·벌점·운영 기록 수와 오래된 날짜를 표시합니다.
- 용량은 D1이 반환한 `size_after` 메타데이터로 표시하며 조회값이 없으면 0이 아닌 ‘확인 필요’로 표시합니다.
- DB의 이미지·인덱스·내부 자료도 전체 저장 용량에 포함됩니다. 레코드를 삭제해도 DB 파일이 바로 작아지지 않고 재사용할 빈 공간이 될 수 있습니다.
- 70% 확인 권장, 85% 주의, 95% 조치 필요로 표시합니다.
- 일일 D1 읽은 행/쓴 행과 Workers 요청은 **연결한 Cloudflare 계정 전체** 기준입니다. 다른 사이트·DB가 같은 계정에 있으면 함께 집계됩니다.
- 통계는 최대 5분 캐시하고 마지막 집계 시각·갱신 실패 여부를 표시합니다. Cloudflare의 집계 지연·샘플링이 있을 수 있습니다. 한국 시간 오전 9시(UTC 00시)에 일일 한도가 초기화됩니다.
- CPU P99는 관측한 요청들의 참고 지표입니다. 평균적인 값이 작아도 개별 요청의 10ms 초과를 보장해서 막을 수 없습니다.
- 이 기능은 사용량을 확인하는 도구입니다. 무료 한도를 늘리거나 장애·한도 초과를 자동으로 방지하는 기능은 아닙니다.

### 일일 통계 최초 연결

저장 용량·기록 수·CSV·초기화·정리는 연결 없이 사용합니다. **일일 Cloudflare 사용량만** 다음 설정이 한 번 필요합니다.

1. Cloudflare → My Profile → API Tokens → Create Token → Create Custom Token.
2. 권한은 **Account / Account Analytics / Read**, 계정 범위는 이 사이트가 속한 계정만 지정합니다. 전체 API 키나 DB/Worker 수정 권한은 필요하지 않습니다.
3. 발급한 토큰을 복사합니다. 토큰을 채팅이나 타인에게 보내지 마세요.
4. 사이트 관리자 → 데이터·사용량 관리 → 조회 연결에서 **계정 ID 32자리**, 토큰, 관리자 비밀번호를 입력합니다.
5. 서버가 실제 통계 조회에 성공한 뒤 암호화해 저장합니다. 토큰 원문을 다시 표시하거나 CSV에 넣지 않습니다.
6. 권한·정책 변경으로 조회가 실패하면 마지막 확인값과 경고를 표시합니다. 전날 집계값을 오늘 사용량으로 표시하지 않습니다. 연결 수정·해제도 가능합니다.

계정 ID는 Cloudflare Workers 개요에서 확인합니다. 연결 없이 통계를 0으로 추정하지 않습니다. 외부 API 연동은 형식·오류·보관·권한을 모의 응답으로 검증했으며 사용자의 실제 계정 토큰으로 접속한 것은 아닙니다.

## CSV 내보내기

자료 종류와 시작일·종료일을 선택하고 다운로드합니다. 예약·벌점·운영 기록·학기 마감 이력·동아리 목록을 각각 내보냅니다. 날짜 오름차순이며 예약은 같은 날짜 안에서 시작 시간순입니다. 마감한 벌점도 일반 벌점 CSV에서 학기 이름과 함께 확인할 수 있습니다.

CSV는 명시한 필드만 선택합니다. 이미지, 동방 비밀번호, 계정 비밀번호·해시·암호문, API 토큰, 세션, 예약 확인코드 및 보안 키는 포함하지 않습니다. 예약 CSV는 날짜·시간·장소·동아리·대표자·연락처·예약 상태·사진 확인 상태를 포함하며 자유 메모는 내보내지 않습니다. 벌점 사유와 운영 작업의 대상 문구는 사람이 입력한 일반 텍스트이므로 그곳에 비밀번호를 직접 적지 마세요.

엑셀 한글 표시를 위한 UTF-8 BOM, 쉼표·따옴표·줄바꿈 처리, 수식 실행 방지 처리를 적용했습니다. 200건씩 조회하고 한 파일 최대 10만 건까지 제공합니다. 초과하면 일부만 다운로드하지 않고 기간·동아리 범위를 나누도록 안내합니다. 다운받는 중 다른 운영 자료가 변경되면 섞인 자료를 만들지 않고 처음부터 다시 받도록 안내합니다. 다운로드한 운영 자료는 담당자만 보관하세요.

## 전체·개별 동아리 벌점 초기화

1. **학기 벌점 초기화** 탭에서 처리명을 입력합니다. 예: `2026학년도 2학기 마감`.
2. **전체 동아리 벌점 초기화** 또는 동아리를 선택해 **선택 동아리 벌점 초기화**를 누릅니다. 동아리별 표의 ‘개별 벌점 초기화’도 같은 기능입니다.
3. 확인 창의 대상 동아리·기록 수·감점 합계를 확인합니다.
4. **대상 CSV 다운로드**를 누르고 파일을 열어 확인합니다. 브라우저는 실제 저장·열람을 대신 증명할 수 없으므로 담당자가 직접 확인해야 합니다.
5. 파일 확인 체크, 관리자 비밀번호, 화면의 확인 문구를 입력하고 실행합니다.

사진 미제출·동방점검 벌점을 함께 초기화합니다. 비활성 동아리도 전체 초기화에 포함합니다. 과거 기록을 지우는 대신 마감 표시를 하므로 **현재 합계는 0점**, 이전 기록은 CSV와 마감 이력에 남습니다. 관리자 동방점검·동아리 화면은 마감되지 않은 현재 벌점 기준으로 표시합니다. ‘현재 학기’는 날짜 자동 계산이 아니라 마지막 초기화 후 남은 기록을 뜻합니다.

초기화한 날을 새 벌점 기간의 시작으로 기록합니다. 그 이전 날짜로 사진·점검 벌점을 다시 부과할 수 없습니다. 같은 날짜의 기존 사진 벌점도 중복 적용하지 않습니다. 날짜·대상·CSV 내용 확인 후 실행하세요. 잘못 마감한 기록을 자동으로 되돌리는 버튼은 제공하지 않으며 전체 백업을 따로 보관하는 것이 좋습니다.

현재 진행·예정 예약, 대표 계정, 비밀번호, 로고·공지는 바뀌지 않습니다. 초기화 직후 일반 사용자에게는 새로고침·화면 재진입 후 0점이 표시됩니다. 최근 마감 30건은 화면에서, 전체 이력은 CSV로 조회합니다.

## 이전 기록 정리

- **지난 예약 기록**: 기준일보다 오래된 과거 예약과 연결된 확인코드 자료만 삭제. 오늘·미래 예약은 제외.
- **학기 마감·취소 벌점 기록**: 기준일보다 오래된 마감 기록 또는 취소한 기록만 삭제. 현재 유효한 벌점은 합계 보존을 위해 제외.
- **이전 운영 기록**: 기준일보다 오래된 작업 기록만 삭제. 현재 정리 작업의 기록은 남김.

삭제 대상 미리 확인 → 대상 CSV 다운로드·확인 → 관리자 비밀번호·확인 문구 입력 순서입니다. 기준일 당일은 삭제하지 않습니다. 250건씩 처리하고 진행 수를 표시합니다. 계정·동방 비밀번호·현재 설정·이미지·학기 마감 이력·오늘 이후 일정은 삭제 대상이 아닙니다.

확인 후 자료가 바뀌면 실행하지 않습니다. 나누어 삭제하는 도중 다른 자료가 변경되면 그 시점까지 처리한 건수는 유지하고 멈춥니다. 창을 닫고 남은 대상을 다시 확인·내보내기한 뒤 진행하세요. 재시도로 같은 작업을 중복 실행하지 않도록 처리했습니다. 큰 정리 작업 자체도 무료 읽기·쓰기 사용량에 포함되므로 사용량에 여유가 있을 때 기간을 나누어 진행하세요.

## 완전 복구용 백업

CSV는 열람·보관용이며 전체 복구용 DB 백업과 다릅니다. 업데이트 후 **기존 배포 폴더의 `BACKUP_DATA.cmd`**를 실행하거나 그 폴더에서 `npm run backup`을 실행하면 `backups` 아래에 SQL, 기존 암호화 키, 배포 설정을 보관합니다. Cloudflare 로그인은 기존 PC의 Wrangler 인증을 이용합니다.

전체 백업에는 이미지·암호화된 계정 자료와 복호화에 필요한 키가 포함됩니다. **CSV에는 이런 자료를 넣지 않으며**, 전체 백업은 외부 공유·공개 저장소 업로드를 금지하고 별도로 보관하세요. 웹 관리자 화면에는 전체 백업 방법을 안내합니다. 이 사이트에서 관리자의 PC 명령을 자동 실행하거나 복구용 SQL을 CSV로 내려주지 않습니다.

## 검증 범위

추가 테이블·기존 열을 바꾸지 않는 벌점 마감 연결 테이블·조회 뷰·인덱스·감사 기록 버전 트리거를 0006 마이그레이션으로 적용합니다. 이전 마이그레이션과 운영 자료는 보존합니다. 계정 권한, 비밀번호 재확인, CSV 필드 제한·정렬·페이지, 전체/개별 초기화·이력·기간 보호, 동시 변경 차단·재시도, 삭제 범위와 원자적 실패 복구, 사용량 연동의 암호화·캐시·오류를 검증합니다.

실제 운영 사이트에는 아직 적용하지 않았으며 실제 PC·모바일 브라우저 클릭과 사용자의 Cloudflare 통계 토큰은 직접 검증하지 않았습니다. 적용 후 PC·휴대전화에서 현재 점수·예정 예약 보존, 작은 테스트 범위 CSV와 개별 초기화부터 확인하세요.
