## 보안 판단과 남는 한계

검사 범위에서 새 조회 권한으로 메인 관리 기능을 사용하거나 개인정보 응답을 받는 경로는 확인되지 않았습니다. 이는 모든 공격에 대한 안전 보증이나 외부 전문 보안 감사 인증이 아닙니다.

1. **링크는 소지자 권한입니다.** 다른 사람에게 전달되면 만료 전 사용할 수 있습니다. 날짜/장소/유효 기간을 짧게 지정하고 필요하면 정지합니다. 본인 식별이 필요하면 개인 계정을 사용합니다. 이미 확인·복사·캡처·저장한 내용은 만료나 정지로 회수하지 못합니다.
2. **조회 계정은 요청대로 MFA가 없습니다.** 필요한 직원에게만 발급하고 퇴임 시 사용을 중지합니다. 서버 수정 권한과 신청자 개인정보는 부여하지 않습니다.
3. **메인 계정은 전체 전화번호를 봅니다.** 메인 세션이나 PC·Cloudflare 계정 자체가 탈취되면 접근 범위를 잃을 수 있으므로 플랫폼 MFA와 기존 키/백업 보호가 계속 필요합니다. 이전 보안 검사에서 언급한 비밀번호 KDF·피싱·복구 훈련·운영 관리 한계도 그대로입니다.
4. **운영 검증 범위:** 실제 Windows PC·휴대전화·실제 Cloudflare 무료 계정의 부하·CPU 제한·실제 DB 복원 훈련은 수행하지 않았습니다. 새 유료 서비스는 추가하지 않았지만 기존 무료 한도는 공유합니다. 공개/비공개 설정과 DB ID·보안 키는 업데이트 도구가 유지합니다.

## 검증 범위

- 전체 자동 검사: 215건. 기존 예약 오픈/시간 선택/중복·4시간 제한/취소/추가승인, 대표 계정 60개, 동시 로그인·대여 독점, 벌점/초기화/CSV/정보 수정/안내·배치도 기능을 포함합니다.
- 보안 전용 38건: RFC HOTP 벡터, TOTP 시간 범위·재사용, 인증 전 권한 우회, 복구 코드 경쟁 사용, 10분 미사용, 계정 수정·인증앱 교체, 저장 직전 권한 회수, 개인정보 암호화·전환, 백업 변조·오류 거부를 포함합니다.
- 로컬 Workers + D1: 실제 Worker 번들·WebCrypto·D1 SQL로 MFA, 키 분리, 암호화된 정보 조회, 10분 만료, 기존 예약/벌점/CSV/마감/정리 기능을 검사했습니다.
- 화면: PC 및 390px iframe의 모바일 크기에서 관리자 재인증 입력칸·저장 버튼, QR·수동 키 안내, 복구 코드 표시와 가로 넘침을 확인했습니다. 실제 휴대전화·키보드/인증앱 스캔·실제 Windows PC 검사는 아닙니다.
- 브라우저 인증 보조 도구가 응답하지 않아 실제 사용자 인증 자동 조작은 수행하지 않았습니다. 인증 상태 화면에는 가상 데이터를 사용했고 인증 성공·실패·변경은 자동 API 검사와 로컬 Worker 런타임에서 확인했습니다.
- Windows용 업데이트 경로는 한글·공백·작은따옴표가 있는 경로에서 실제 Node 자식 프로세스 및 가상 Wrangler로 검사했습니다. 실제 Cloudflare 업로드·키 등록·원격 데이터 전환은 사용자 PC에서 적용해야 합니다.
- 백업은 암호화 파일 복호화와 이전 백업 전환을 검사했습니다. 사용자 운영 DB로 실제 복구하는 훈련은 수행하지 않았습니다. 백업 암호 입력이 터미널에 표시되지 않는 것도 확인했습니다.

동일 예약을 8개 요청으로 동시에 재시도하는 경우 기존 확정 결과를 일관되게 돌려주도록 수정하고 회귀 검사를 추가했습니다. 재검사 중 확인한 재인증 기록과 초기화 대상 버전의 충돌을 분리된 보안 기록으로 해결했습니다. 보안 기록은 1,000건으로 제한하며 비밀번호·OTP·복구 코드·개인정보 원문을 기록하지 않습니다. 캐시 갱신·이전 작업 정리의 최종 권한 검사도 보강했습니다.

## 남는 한계와 다음 강화 대상

1. **Cloudflare 계정 자체의 MFA**는 직접 켜야 합니다. 플랫폼 계정이 탈취되면 Worker 코드·키·D1을 변경할 수 있으므로 사이트의 관리자 MFA만으로 막을 수 없습니다.
2. **피싱·이미 로그인한 PC의 탈취**: TOTP가 모든 피싱을 막지는 못합니다. 다음 단계로 패스키, 개인별 관리자 계정 및 조회/수정 권한 분리가 유용합니다. 유효한 관리자 세션으로 내려받은 화면·CSV의 유출까지 DB 암호화가 막아주지는 않습니다.
3. **과거 사본**: 전환 전 D1 Time Travel 복구 지점(현재 Free 7일), 다른 폴더에 복사하거나 이미 공유한 원문 백업, PC 파일 버전과 디스크 잔여 정보까지 이번 업데이트가 재암호화하거나 삭제하지는 못합니다.
4. **비밀번호 해시 정책**: Workers 호환성을 위해 PBKDF2-SHA256 100,000회와 서버의 비밀 pepper를 사용합니다. OWASP의 PBKDF2-SHA256 600,000회 기준과는 차이가 남습니다. 배포 플랫폼의 실제 제한·무료 CPU 범위를 확인한 뒤 더 강한 KDF 또는 작업량으로 전환하는 후속 검증이 필요합니다. 기존 비밀번호를 임의로 바꾸지는 않았습니다. 백업 암호 파생에는 로컬 PC에서 scrypt N=131072/r=8/p=1을 사용합니다.
5. **보관 기간·운영 관리**: 임원 변경·학기 종료 시 필요 없는 개인정보의 삭제와 키/백업의 별도 오프라인 보관, 복구 훈련이 필요합니다. 보호된 이미지·CSV 다운로드도 권한 있는 관리자가 의도적으로 공유하는 것까지 차단하지는 않습니다.
6. **상시 유지보수**: npm audit의 0건은 검사 시점에 등록된 공지 기준입니다. 새 공지·공급망 공격·운영 부하·무료 한도 소진까지 없다는 뜻은 아닙니다. 이번 변경에 유료 서비스는 추가하지 않았습니다.
