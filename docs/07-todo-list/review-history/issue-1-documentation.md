# Issue #1 문서 재편 수행 계획과 검증 범위

작성일: 2026-11-06 (Asia/Seoul). 기준 커밋: `5ee7101a9bb598033ee5aefdc34d2901101ff372`. 요구사항 원본은 [Issue #1](https://github.com/gu2417/Ila-reservation-system/issues/1)입니다.

## 설계와 범위

루트의 기능별 업데이트 기록과 현행 설명이 섞여 있는 문제를 해결하기 위해, 이슈에서 지정한 7개 상위 디렉터리를 그대로 사용합니다. 새로운 문서 사이트나 의존성은 추가하지 않습니다. 각 분야의 목차에서 현행 설명과 이전 기록을 구분하고, 루트 README는 진입점·설치·운영 주의만 남깁니다.

원래 루트 Markdown은 README 포함 16개입니다. 15개는 해당 분야로 실제 이동하고, 원래 README의 긴 설치·업데이트 설명도 개요의 역사 문서로 보존합니다. 문서 내용 중 경로 안내만 새 상대 링크로 정비합니다. 상세 [이전표](../../04-file-structure/document-migration.md)를 기준으로 전후 누락을 검사합니다.

## 수행 순서

1. **조사:** 원문 전수 조사, source/test/migration과 비교, 현행 정책과 과거 버전 구분.
2. **이동:** `git mv`로 원문 이전, 각 분야에 README와 복수 현행 문서 작성. 문서 분야별 작성은 서로 다른 폴더에서 병렬 진행.
3. **운영 호환:** 업데이트 도구의 루트 문서 목록을 새 `docs/` 재귀 복사로 전환. README·배치 파일·고지문·설정·키 보호와 기존 백업 순서 유지.
4. **회귀 검증:** 문서 링크/목차·원문 보존·파일 구조, 중첩 문서 업데이트와 기존 문서 백업을 검사. 타입·빌드·전체 자동 검사와 Worker 로컬 검증 실행.
5. **리뷰와 병합:** 독립 리뷰에서 요구사항·문서 정확성·운영 경로 변경을 확인하고 상세 PR 작성 후 검사 상태를 확인해 머지.

## 증거의 해석

원래 REVIEW의 215/234/244/270/271건 기록은 각 당시 릴리스의 증거로 남깁니다. 이번 PR의 검증 명령·결과·리뷰는 PR 본문에 별도로 기록합니다. 실제 운영 배포, 원격 DB 변경, 비밀키 등록, 사용자 PC·실기기 UI 검증은 이 문서화 작업에서 실행하지 않습니다.
